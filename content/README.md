# content — всё, что публикуется

Одна папка на все каналы. Внутри: **канал → бренд → вид контента**.

```
content/<канал>/<бренд>/
  queue.json        очередь аккаунта: что и когда выходит
  published.json    архив вышедшего: когда и под каким id
  photo/            карусели и фото
  video/            ролики
```

| Канал                | Статус                        | Типы                        |
| -------------------- | ----------------------------- | --------------------------- |
| `instagram/`         | **публикуется по расписанию** | `carousel`, `reel`          |
| `youtube/`           | папки готовы, публикации нет  | `short`, `video`            |
| `threads/`           | папки готовы, публикации нет  | `carousel`, `image`, `text` |
| `tiktok/`            | папки готовы, публикации нет  | `video`                     |
| `../tg-images/`      | работает отдельно, вне `content/` | картинки к постам       |

Контент можно класть в очередь **до** того, как подключена публикация: он
дождётся её в папке канала.

## Три правила

**Одна очередь на аккаунт, а не на вид.** Файлы разведены по `photo/` и
`video/`, потому что это разные процессы производства. Очередь общая: она
описывает расписание ленты, а лента у аккаунта одна — с двумя очередями легко
поставить карусель и ролик на одно время и выдать два поста подряд.

**Тип виден по имени папки**, сразу после даты:
`photo/2026-09-25-**carousel**-robotics-expedition`,
`video/2026-09-26-**reel**-china-hook`.

**Путь опубликованного поста менять нельзя.** Instagram не принимает файлы
напрямую — он скачивает медиа по публичной ссылке на этот путь, и ссылка
остаётся вшитой в вышедший пост. Переносить и переименовывать можно только то,
что ещё не опубликовано.

## Руками сюда обычно не ходят

Папки и очереди создаются скриптами:

```bash
npm run q                  посмотреть весь план по всем каналам
npm run q:add -- ...       положить готовый контент в очередь
npm run publish -- --due   опубликовать то, чему наступило время
```

Реестр каналов и брендов — `remotion-video-tools/scripts/channels.mjs`.
Что нужно для подключения остальных каналов —
[docs/channels.md](../remotion-video-tools/docs/channels.md).
