# instagram — хранилище и очередь публикаций

Отдельное от роликов место: сюда складывается **готовый к публикации** контент
для Instagram и архив того, что уже вышло. Устроено так же, как `tg-images`
для Telegram: репозиторий хранит файлы, публикующая сторона забирает их по
прямым ссылкам.

## Структура

```
instagram/
  queue.json                     очередь: что и когда публиковать
  published.json                 архив: что уже вышло, когда и под каким id
  posts/
    2026-09-25-robotics-expedition/
      01-cover.png … 08-cta.png  слайды карусели по порядку
      caption.txt                подпись поста
      meta.json                  тип, дата публикации, статус
```

Папка поста **не удаляется после выхода** — по ней всегда видно, что именно
было опубликовано. Имя папки начинается с даты публикации, поэтому архив
читается хронологически.

## Как сюда попадает контент

```bash
# 1. Собрать карусель (в remotion-video-tools)
npm run carousel -- --input data/carousel-robotics-expedition.json

# 2. Положить её в очередь на конкретную дату
npm run ig:add -- --carousel robotics-expedition \
  --at "2026-09-25 10:00" --caption-file data/caption-robotics.txt

# 3. Посмотреть, что в очереди и что уже вышло
npm run ig:queue
```

## Как контент уходит в Instagram

По расписанию GitHub Actions (`.github/workflows/instagram-publish.yml`)
запускает публикацию постов, у которых наступило время. Instagram забирает
картинки по прямым ссылкам вида
`https://raw.githubusercontent.com/Ostap-87/MyFirst/master/instagram/posts/<папка>/01-cover.png`.

Токен доступа лежит в секретах репозитория, в файлах его нет. Что настроить
один раз — в `remotion-video-tools/docs/publishing.md`.

## Правила

- **Ссылки не переиспользуются.** Каждая публикация лежит в своей папке с
  датой. Если пересобрали карусель — это новая папка, а не перезапись старой:
  Instagram кэширует картинки, и подмена файла ломает уже вышедший пост.
- **Статусы в очереди:** `queued` — ждёт даты, `publishing` — в работе,
  `published` — вышел (запись уезжает в `published.json`), `failed` — ошибка,
  причина записана в `error`.
- **Подпись правится до публикации.** После выхода менять `caption.txt`
  бессмысленно — в Instagram текст уже ушёл.
