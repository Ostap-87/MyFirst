# Бесплатные источники: что забрали, где лежит, как применять

Решение владельца 03.10.2026: «эффект с киношной коррекцией — забрать в
арсенал, иконки отлично, всё, что можно взять с этих сайтов бесплатно, —
забрать, дальше тестируем». Здесь — реестр того, что взято, на каких
условиях и какой командой это кладётся в кадр. Демо всего набора —
`Shared-SourcesLab` (`src/shared/SourcesLab.tsx`), ролик «Проба источников —
LUT, Phosphor, Lottie, Mixkit, React Bits (40 с, тест)».

Сторонние файлы лежат в `public/local/` и в репозиторий не коммитятся
(кроме иконок Phosphor — они маленькие и под MIT). На новой машине всё
восстанавливает одна команда: `scripts/fetch-sources.sh` (или `… lottie`,
`… mixkit` по отдельности).

## 1. Киношная цветокоррекция — `scripts/grade.sh`

Идея с freshluts.com (LUT-пресеты), но сами `.cube` там только после
регистрации, поэтому коррекция сделана фильтрами ffmpeg и работает без
сторонних файлов. Это штатный шаг подготовки Head.

```bash
scripts/grade.sh <in.mp4> <out.mp4> [пресет] [сила 0..1] [lut.cube]
npm run head -- --prepare s40 --grade            # cinematic, сила 1
npm run head -- --prepare s40 --grade warm --grade-strength 0.6
```

| Пресет | Характер | Когда |
| --- | --- | --- |
| `cinematic` | холодные тени, чуть приглушённая насыщенность, лёгкая резкость | по умолчанию; это «до/после» из демо 03.10 |
| `warm` | тёплые полутона, кожа румянее | улица в пасмурную погоду |
| `clean` | без оттенка: контраст и чистота | кадры с логотипами и экранами |
| `teal` | лёгкий teal & orange | динамичные уличные сцены |
| `lut` | внешний `.cube` пятым аргументом | когда владелец скачает LUT со своего аккаунта Fresh LUTs в `public/local/luts/` |

Сила меньше 1 — смешивание с исходником. Звук копируется без перекодирования,
видео — H.264 crf 18. В `--prepare` коррекция идёт после поворота и до
подтяжки, стоп-кадр «01a-cvetokorrekciya.jpg» показывается владельцу вместе
с исходником. Правило: лицо не перекрашиваем — все пресеты мягкие.

## 2. Иконки Phosphor — `public/icons/phosphor/{bold,fill,regular}/`

phosphoricons.com, лицензия MIT (`public/icons/phosphor/LICENSE`). Полный
набор, по 1512 SVG в трёх весах: `bold` — для плашек и орбиты, `fill` — для
крупных пиктограмм на цветных кружках, `regular` — для мелких подписей.
Имя файла: `<name>-bold.svg`, `<name>-fill.svg`, `<name>.svg` (regular).

Как класть в кадр: `<Img src={staticFile("icons/phosphor/bold/factory-bold.svg")} />`
с `filter: "invert(1)"` для белой иконки на тёмном. Готовые приёмы:
`IconOrbit` (иконки на орбите вокруг слова), `CheckList` (пункты с
галочками, иконка слева), `Tag` в SourcesLab (иконка + подпись).
Пакет `@phosphor-icons/react` не подключали — новая зависимость, SVG хватает.

## 3. Lottie-анимации — `public/local/lottie/*.webm`

lottiefiles.com, бесплатные анимации сообщества (Lottie Simple License:
коммерческое использование, без указания автора). Пакет `@remotion/lottie`
не подключали (новая зависимость): анимация пререндерится в прозрачный
WebM `scripts/lottie-render.cjs` и кладётся в кадр как видео:

```tsx
<OffthreadVideo src={staticFile("local/lottie/check.webm")} transparent muted />
```

Пример с хвостом (последний кадр держится после конца анимации) —

## 5. Идеи React Bits — переписаны как эффекты

reactbits.dev (MIT) — библиотека браузерных анимаций на времени и курсоре;
в Remotion напрямую не работает, поэтому приёмы переписаны от номера кадра
(детерминированный рендер) в `src/shared/components/effects/`:

| Эффект | Идея с сайта | Для чего |
| --- | --- | --- |
| `AuroraBackdrop` | Aurora | мягкий цветной фон под цифры и карточки |
| `BeamsBackdrop` | Beams | косые лучи на тёмном фоне, «технологично» |
| `DotGrid` | Dot Field | волна по сетке точек, фон под графики |
| `ShinyText` | Shiny Text | блик по заголовку и призыву |
| `IconOrbit` | Orbit Images | иконки Phosphor на орбите вокруг слова |

Параметры — в `src/shared/components/effects/README.md`.

## 6. Что не взяли и почему

- **Fresh LUTs**: файлы `.cube` отдаются только после регистрации, чужие
  аккаунты не заводим. Владелец скачивает сам → `public/local/luts/` →
  `grade.sh … lut 1 public/local/luts/<файл>.cube`.
- **`@remotion/lottie`, `@phosphor-icons/react`**: новые зависимости, нужны
  только ради удобства; пререндер и SVG дают тот же результат.
- **Mixkit 4k**: только с аккаунтом; для вертикали 1080×1920 достаточно.
