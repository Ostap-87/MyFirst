# Говорящая голова: как собирается ролик

Метод выведен на разборе съёмки из Циндао (`GTT-ChinaReel`). Здесь порядок
действий и правила, каждое из которых появилось после конкретной ошибки —
поэтому рядом с правилом написано, чем она обошлась.

## Порядок работы

1. **Взять исходник с камеры, а не из редактора.**
2. Разобрать: длительность, разрешение, звук, склейки, вшитые титры.
3. **Подтянуть: вырезать паузы и мычание** (`npm run tighten`).
4. Уложить в нужную длительность — ускорением, не обрезкой.
5. Убрать блеск с лица, выровнять звук.
6. Расшифровать речь и вычитать расшифровку.
7. Найти, где в записи лежит главное — и решить, доживёт ли зритель до него.
8. Собрать раскадровку и согласовать её **до** рендера.
9. Отрендерить стоп-кадры ключевых моментов, а не весь ролик.
10. Полный рендер — последним.

Порядок не переставлять: каждый шаг сдвигает тайминги следующего. Расшифровка
делается после подтяжки и ускорения, иначе секунды плашек окажутся не теми.

## Правила

### 1. Исходник — только с камеры

Файл из онлайн-редактора приносит чужой водяной знак, вшитые титры, ужатое
разрешение и уже изменённый темп. Всё это потом маскируется костылями.

На этом ролике присланный из Kapwing файл стоил трёх версий монтажа:
полоса размытия, обрезка низа, увеличение кадра. Чистый исходник с iPhone
выключил всю маскировку одним флагом и дал 1080×1920 вместо апскейла с 720p.

### 2. Длительность проверять по содержанию, а не по секундам

Перед любой обрезкой — посмотреть, что попадёт под нож. На этом ролике
обрезка до 25,5 с вырезала бы все четыре названия компаний: в оригинале они
звучат на 26,4—30,7 с, а крючок обещал именно их.

**Ускорение вместо обрезки.** Если нужно уложиться в длительность, а речь
не влезает — ускорять через `atempo` (сохраняет высоту голоса), а не резать
смысл. Коэффициент: `длительность_оригинала / нужная_длительность`.

```bash
ffmpeg -i orig.mp4 -filter_complex \
  "[0:v]setpts=PTS/1.343[v];[0:a]atempo=1.343,loudnorm=I=-14:TP=-1.5:LRA=11[a]" \
  -map "[v]" -map "[a]" -r 30 out.mp4
```

### 3. Паузы и мычание вырезаются до всего остального

В живой речи на улице пауз обычно 15—20% хронометража. На этом ролике —
**6,4 секунды из 34,2**, почти пятая часть. Зритель Reels уходит именно на
таких провалах: картинка стоит, звук молчит.

```bash
npm run tighten -- --video public/local/файл.mp4 --dry-run   # сначала посмотреть
npm run tighten -- --video public/local/файл.mp4             # потом резать
```

- **Паузы укорачиваются, а не убираются.** Речь без пауз звучит роботом.
  По умолчанию длинная пауза подрезается до 0,18 с.
- **Заполнители «ээ», «ммм», «эм» режутся целиком** — они не несут смысла.
  Нужна расшифровка: флаг `--captions`.
- **Мусорные слова только через `--junk`, осознанно.** «Ну», «вот»,
  «значит», «типа» — полноценные слова. Вырезать их вслепую значит ломать
  интонацию: на склейке слышен щелчок, а фраза теряет ритм. Добавлять их в
  список стоит, когда человек действительно ими злоупотребляет.
- **Порог тишины подбирается по съёмке.** На улице шум машин держит фон
  высоко: −32 dB не сработал вовсе, −40 dB нашёл все десять пауз.

**Это первый шаг, не последний.** Вырезание сдвигает тайминги речи, поэтому
расшифровку после него делать заново. Побочная выгода: после подтяжки
нужное ускорение падает почти до единицы, и голос звучит естественно —
на этом ролике вместо 1,343 хватило бы 1,09.

### 4. Главное не должно лежать в хвосте

В исходной записи самое ценное почти всегда в конце: человек разгоняется.
В Reels до конца доходит меньшинство.

Лечится не перестановкой (речь склеивать нельзя — слышно), а **крючком в
первой секунде, который обещает то, что прозвучит в конце**. Зритель
остаётся ради ответа.

### 5. Тайминги — из расшифровки, никогда на глаз

Плашки, геометки, акценты ставятся по секундам из `npm run transcribe`.
Сдвиг на полсекунды читается как брак.

```
Alibaba 21.09   Tencent 21.72   Baidu 22.34   Haier 22.84
```

**Расшифровку вычитывать обязательно.** Она уходит в кадр субтитрами, и
ошибка распознавания становится ошибкой в ролике. На этом ролике whisper
выдал «Hire» вместо «Haier», «Циндау» вместо «Циндао», «МРИФМУ» вместо
«рифму» — семь правок на 43 слова.

### 6. Место для элементов выбирается по кадрам, а не по сетке

Прежде чем ставить плашки в угол — отрендерить кадры тех секунд, когда они
появятся, и посмотреть, что там. На этом ролике правый верхний угол оказался
свободен (небо и листва) во всех четырёх моментах, левый — занят лицом.

Проверять примеркой: нарисовать прямоугольник будущей плашки прямо на кадре.

### 7. Субтитры не на лице

Нижняя треть вертикального кадра — зона подписи и кнопок Instagram, а
середина — лицо. Субтитры ставятся на плечи: ниже подбородка, выше 1600 px.

### 8. Блеск с лица снимается маской, а не кривыми

Глобальные кривые тянут весь кадр и блик не убирают: он локальный.
Работает маска по ярким участкам плюс подмена смягчённой версией.

```bash
[0:v]format=yuv444p,split=3[base][soft][m];
[soft]boxblur=26:1,curves=all='0/0 0.5/0.5 0.75/0.70 1/0.88'[sb];
[m]format=gray,geq=lum='clip((lum(X,Y)-175)*3.4,0,255)',boxblur=26:1,format=yuv444p[mask];
[base][sb][mask]maskedmerge
```

Сначала замерить, сколько выбито в белое. Если больше нескольких процентов —
детали не вернуть, маска только смягчит. На этом ролике было 1,18%, поэтому
блик ушёл полностью.

### 9. Звук приводится к норме площадки

`loudnorm=I=-14:TP=-1.5:LRA=11` — целевой уровень Instagram. Исходник с
телефона обычно идёт с пиком у самого нуля: на этом ролике было −0,4 dB,
на грани клиппинга.

### 10. Всё, что подбирается глазами, — в пропы

Скорость вращения, размер логотипа, текст крючка. Полный рендер занимает
три с половиной минуты; подбирать параметр перерендерами — потерянный час.
С пропом хватает фрагмента в 150 кадров.

### 11. Смотреть стоп-кадры до полного рендера

`npx remotion still <id> out/f.png --frame=N` занимает секунды. На этом
ролике стоп-кадры поймали три ошибки до рендера: субтитры уехали к верхней
кромке, крючок был нечитаем на светлом дорожном знаке, тонкий гарамон
геометки тонул на пересвеченном небе.

### 12. Позиционировать обёртку, а не `OffthreadVideo`

Свои стили `position` он до элемента не доносит — кадр уезжает, по краям
появляются чёрные поля.

```tsx
<div style={{ position: "absolute", left, top, width, height }}>
  <OffthreadVideo src={...} style={{ width: "100%", height: "100%" }} />
</div>
```

### 13. Тяжёлое — в `public/local/`

Исходники, промежуточные версии, wav. Папка в `.gitignore`. В репозиторий
идут только код и расшифровка: по ним ролик пересобирается целиком.

## Что ещё стоит помнить

- **Съёмка без очков.** В говорящей голове глаза — главный канал контакта,
  без них удержание заметно ниже.
- **Геометку сверять с метаданными.** iPhone пишет GPS: на этом ролике
  координаты указывают на Вэйфан, в 150 км от Циндао.
- **Чужие логотипы — решение заказчика.** Товарные знаки в ролике могут
  прочитаться как заявление о партнёрстве. Текстовая плашка такого
  впечатления не создаёт.
