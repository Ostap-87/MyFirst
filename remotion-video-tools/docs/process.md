# Как делаем ролики: порядок, сделанное, эффекты

Документ для владельца и для работы над любым роликом. Правила, на которых
он держится, — в `CLAUDE.md` («Факты GTT», «Платные сервисы»).

## 1. Порядок работы над любым роликом

Между этапами — «да» владельца. Платные сервисы (Higgsfield, ElevenLabs)
подключаются только на этапе 7: сначала цена, потом согласие.

| № | Этап | Что делается | Что видит владелец |
| - | ---- | ------------ | ------------------ |
| 0 | **Бриф** | Формат, площадка (сторис или Reels), длина, язык, главная мысль. Сверка с фактами GTT: «более 1000 компаний в базе», «быстрое согласование». | Короткий бриф |
| 1 | **Материалы** | Своя съёмка, фото, запись сайта, логотипы. Тяжёлое — в пул `public/local/` (каталог `data/pool.md`), в репозиторий не коммитится. | Список материалов |
| 2 | **Сценарий** | Текст по репликам с хронометражем. Если владелец снимает сам — тексты для записи (пример: `docs/scripts/site-tour-texts.md`). | Текст целиком |
| 3 | **Подготовка съёмки** — бесплатно | Поворот, вырезка пауз и мычания (`npm run tighten`), чистка голоса локальной моделью, расшифровка (`npm run transcribe`), вычитка субтитров. | «До/после» звука, расшифровка |
| 4 | **Черновой звук** — бесплатно | Если нужен синтез голоса — черновик локально, только чтобы выверить темп и монтаж. | Черновик звука |
| 5 | **Монтажный стол** — бесплатно | Раскладка по секундам: плашки, окна, вставки, логотипы, эффекты (`npm run editor`, `scripts/site-tour-table.py`). | Таблица таймингов и стоп-кадры в полный размер, по одному |
| 6 | **Черновой рендер** — бесплатно | Полный ролик в низком качестве. Правки собираются одним списком. | Черновик целиком |
| 7 | **Платный финал** | Только утверждённый текст: один дубль на реплику, цена заранее (`get_cost`). Сбойный дубль переделывается после согласования. | Цена → «да» |
| 8 | **Финальный рендер** | Сторис и/или Reels, музыка тихо под голосом, проверка громкости (−16 LUFS) и текста (расшифровка готового файла). | Готовые файлы |
| 9 | **Сдача** | Сжатые версии для отправки, коммит в `InsTilYou`, при необходимости — очередь публикации (`npm run q:add`). | Файлы и ссылки |

## 3. Эффекты, которые можно применять

Все эффекты — в `src/shared/components/effects/` (подробно — README там же),
общие компоненты — в `src/shared/components/`.

**Текст и цифры**
- `KaraokeCaptions` — субтитры с подсветкой слова: три стиля (тень, обводка,
  плашка), пять шрифтов.
- `CountUp` — отсчёт числа с торможением к финалу.
- `StatBadge` — цифра в плашке («1000+ компаний в базе»).
- `TickerTape` — бегущая строка с брендами.
- `TypingLine` — текст печатается на глазах.
- `StepNumber` — номера пунктов.
- `LowerThird` — подпись спикера.
- `StickyCTA`, `CtaCard` — призыв, сайт, «10 дней».
- `EndCard` — финал с логотипом.
- `Watermark` — ник в углу кадра на весь ролик.

**Вокруг говорящей головы**
- `PopWindows` — окна с фото или логотипами выскакивают вокруг спикера.
- `PhotoCards` — фотокарточки внахлёст.
- `FramedInsert` — видео в рамке с подписью.
- `WipeBroll` — перебивка на весь кадр шторкой.
- `SplitScreen` — деление экрана снизу или сбоку.
- `PipScreen` — спикер сжимается в окно в углу.
- `CutoutStage` — спикер без фона перед показом.
- `AngleCuts` — смена ракурса второй камерой.
- `CameraMoves` — резкий наезд, плавный наезд, дрожь.
- `SlowZoom` — «дыхание» кадра.

**Сайт и телефон**
- `LaptopCapture` — ноутбук с живой записью сайта, адресом и курсором.
- `PhoneCapture`, `PhoneMockup` — телефон с сайтом.
- `SiteShowcase` — телефон в 3D.
- `SiteCutaway` — прокрутка скриншота страницы.
- `RouteChips` — маршрут по городам.
- `ChatOverlay` — переписка.

**Переходы и фактура**
- `GlitchTransition` — глитч между сценами.
- `FadeIn`, `SlideInSpring` — плавное появление и выезд с пружиной.
- `ZoomParallax` — наезд на фото с параллаксом текста.
- `Shimmer` — блик по тексту и логотипу.
- `FilmGrain` — плёночное зерно.
- `MotionTrail` — шлейф движения.
- `SpinningTetra`, `TetraField` — 3D-знак GTT.
- `GiphySticker` — стикеры и гифки с канала Giphy (`npm run giphy`).

**Звук**
- Чистка голоса «под студию» — локально, бесплатно.
- Вырезка пауз и мычания (`npm run tighten`).
- Музыкальная подложка с плавным входом и выходом (проп `music` /
  `musicVolume` в SitePromo и Head).
- `SoundCue` — щелчки на появление плашек (`npm run make-sfx`).

**Форматы-конвейеры** (каталог — `.claude/skills/video-format/SKILL.md`)
- Head — говорящая голова.
- Recut — плашки поверх готовой съёмки.
- Post — ролик по посту контент-плана.
- Cards — карусель.
- Stats — ролик на цифрах.
- Intro — заставка бренда.
- Промо сайта — запись экрана, ноутбук и телефон.
