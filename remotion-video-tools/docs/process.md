# Как делаем ролики: порядок, сделанное, эффекты

Документ для владельца и для работы над любым роликом. Правила, на которых
он держится, — в `CLAUDE.md` («Факты GTT», «Платные сервисы»).

## 1. Порядок работы над любым роликом

Между этапами — «да» владельца. Платные сервисы (Higgsfield, ElevenLabs)
подключаются только на этапе 7: сначала цена, потом согласие.

| № | Этап | Что делается | Что видит владелец |
| - | ---- | ------------ | ------------------ |
| 0 | **Бриф** | Формат, площадка (сторис или Reels), длина, язык, главная мысль. Сверка с фактами GTT: «более 1000 компаний в базе», «быстрое согласование». | Короткий бриф |
| 1 | **Материалы** | Своя съёмка, фото, запись сайта, логотипы. Тяжёлое — в пул `public/local/` (каталог `data/pool.md`), в репозиторий не коммитится. | Список материалов |
| 2 | **Сценарий** | Текст по репликам с хронометражем. Если владелец снимает сам — тексты для записи (пример: `docs/scripts/site-tour-texts.md`). | Текст целиком |
| 3 | **Подготовка съёмки** — бесплатно | Поворот, киношная цветокоррекция (`--grade`, пресеты в [docs/sources.md](./sources.md)), вырезка пауз и мычания (`npm run tighten`), чистка голоса локальной моделью, расшифровка (`npm run transcribe`), вычитка субтитров. | «До/после» картинки и звука, расшифровка |
| 4 | **Черновой звук** — бесплатно | Если нужен синтез голоса — черновик локально, только чтобы выверить темп и монтаж. | Черновик звука |
| 5 | **Монтажный стол** — бесплатно | Раскладка по секундам: плашки, окна, вставки, логотипы, эффекты (`npm run editor`, `scripts/site-tour-table.py`). Для Head — по набору элементов и монтажному промпту из [docs/head-style.md](./head-style.md). | Таблица таймингов и стоп-кадры в полный размер, по одному |
| 5а | **Судья** — бесплатно | Отдельный проход по стоп-кадрам всех вставок: единство стиля, интерес, уместность, чистота кадра. Вердикт на каждую: оставить / поправить / убрать; переделываются только явно плохие ([docs/head-style.md](./head-style.md), раздел 6). Повторяется перед финальным рендером. | Таблица: что поправлено и почему |
| 6 | **Черновой рендер** — бесплатно | Полный ролик в низком качестве. Правки собираются одним списком. | Черновик целиком |
| 7 | **Платный финал** | Только утверждённый текст: один дубль на реплику, цена заранее (`get_cost`). Сбойный дубль переделывается после согласования. | Цена → «да» |
| 8 | **Финальный рендер** | Сторис и/или Reels, музыка тихо под голосом, проверка громкости (−16 LUFS) и текста (расшифровка готового файла). | Готовые файлы |
| 9 | **Сдача** | Сжатые версии для отправки, коммит в `InsTilYou`, при необходимости — очередь публикации (`npm run q:add`). | Файлы и ссылки |

## 3. Эффекты, которые можно применять

Все эффекты — в `src/shared/components/effects/` (подробно — README там же),
общие компоненты — в `src/shared/components/`.

**Текст и цифры**
- `KaraokeCaptions` — субтитры с подсветкой слова: три стиля (тень, обводка,
  плашка), пять шрифтов.
- `CountUp` — отсчёт числа с торможением к финалу.
- `StatBadge` — цифра в плашке («1000+ компаний в базе»).
- `TickerTape` — бегущая строка с брендами.
- `TypingLine` — текст печатается на глазах.
- `StepNumber` — номера пунктов.
- `LowerThird` — подпись спикера.
- `StickyCTA`, `CtaCard` — призыв, сайт, «10 дней».
- `EndCard` — финал с логотипом.
- `Watermark` — ник в углу кадра на весь ролик.

**Вокруг говорящей головы**
- `PopWindows` — окна с фото или логотипами выскакивают вокруг спикера.
- `PhotoCards` — фотокарточки внахлёст.
- `FramedInsert` — видео в рамке с подписью.
- `WipeBroll` — перебивка на весь кадр шторкой.
- `SplitScreen` — деление экрана снизу или сбоку.
- `PipScreen` — спикер сжимается в окно в углу.
- `CutoutStage` — спикер без фона перед показом.
- `AngleCuts` — смена ракурса второй камерой.
- `CameraMoves` — резкий наезд, плавный наезд, дрожь.
- `SlowZoom` — «дыхание» кадра.
- `MascotRig` — оживление фигурки-стикера: лапка ходит вниз-вверх, глаза
  моргают, знак на груди. Фигурку НЕ режем на слои — любой стык (растр,
  вектор, обрезка по плечу) виден как рваная линия. Вместо этого
  `scripts/cat-warp.py` плавно деформирует всю картинку (puppet warp): голова
  и воротник — якорь, ладошка едет, предплечье между ними тянется; на выходе
  цикл из 75 кадров с прозрачным фоном, эффект их просто показывает.

**Сайт и телефон**
- `LaptopCapture` — ноутбук с живой записью сайта, адресом и курсором.
- `PhoneCapture`, `PhoneMockup` — телефон с сайтом.
- `SiteShowcase` — телефон в 3D.
- `SiteCutaway` — прокрутка скриншота страницы.
- `RouteChips` — маршрут по городам.
- `ChatOverlay` — переписка.

**Переходы и фактура**
- `GlitchTransition` — глитч между сценами.
- `FadeIn`, `SlideInSpring` — плавное появление и выезд с пружиной.
- `ZoomParallax` — наезд на фото с параллаксом текста.
- `Shimmer` — блик по тексту и логотипу.
- `FilmGrain` — плёночное зерно.
- `MotionTrail` — шлейф движения.
- `SpinningTetra`, `TetraField` — 3D-знак GTT.
- `GiphySticker` — стикеры и гифки с канала Giphy (`npm run giphy`).
- `AuroraBackdrop`, `BeamsBackdrop`, `DotGrid`, `ShinyText`, `IconOrbit` — приёмы
  React Bits, переписанные от номера кадра.

**Сторонние материалы** (реестр и лицензии — [docs/sources.md](./sources.md),
восстановление на новой машине — `scripts/fetch-sources.sh`)
- Цветокоррекция съёмки `scripts/grade.sh` (cinematic / warm / clean / teal / свой LUT).
- Иконки Phosphor, полный набор в трёх весах — `public/icons/phosphor/`.
- Lottie-анимации, пререндер в прозрачный WebM — `public/local/lottie/`
  (`scripts/lottie-render.cjs`): галочки, рост, рукопожатие, ракета, самолёт,
  глобус, сеть, метка, кубок, конфетти.
- Вертикальные клипы Mixkit 1080×1920 — `public/local/mixkit/`: город ночью
  и на закате с воздуха, шоссе, офис, упаковка, рукопожатие.

**Звук**
- Чистка голоса «под студию» — локально, бесплатно: `scripts/voice-studio.sh`
  (DeepFilterNet3 два прохода → гейт по расшифровке `voice-gate.py` → мягкий
  эквалайзер → компрессор → loudnorm −16). Утверждено владельцем 01.10 как
  вариант «A». История: Resemble `denoise` + эквалайзер «−2 на 250, +2 на
  3,2 кГц» — «звук из трубы»; сильный эквалайзер поверх уже обработанного
  звука (срез 320 Гц −6…−8, подъём 3–10 кГц +4…+5) — «шумы и хрип», все
  девять роликов забракованы. Генеративные модели (VoiceFixer, Resemble
  `enhance`) — хрип. Важно: голос всегда брать из исходника (`tighten
  --audio-only --fps 30` по той же сетке), а не из обработанной копии.
  Фоновые звуки в паузах (посуда, пила, чужие голоса) убирает гейт по
  словам расшифровки; внутри речи — только шумодав. DeepFilterNet в venv
  требует правки `df/io.py` (нет `torchaudio.backend` в новых torchaudio) и
  модель DeepFilterNet3.zip из репозитория Rikorose/DeepFilterNet.
- Вырезка пауз и мычания (`npm run tighten`).
- Музыкальная подложка с плавным входом и выходом (проп `music` /
  `musicVolume` в SitePromo и Head).
- `SoundCue` — щелчки на появление плашек (`npm run make-sfx`).

**Форматы-конвейеры** (каталог — `.claude/skills/video-format/SKILL.md`)

- Recut — плашки поверх готовой съёмки.
- Post — ролик по посту контент-плана.
- Cards — карусель.
- Stats — ролик на цифрах.
- Intro — заставка бренда.
- Промо сайта — запись экрана, ноутбук и телефон.

## Рендер без лишнего места на диске

`remotion bundle` копирует всю папку `public` (сейчас больше 5 ГБ) — второй
копии диск не выдерживает. Для одного ролика собираем облегчённую папку из
жёстких ссылок (места не занимает) и передаём её `--public-dir`:

```bash
SP=/tmp/slim-public; mkdir -p $SP/local/head $SP/captions
cp -al public/fonts public/audio public/site $SP/
cp -al public/captions/head-<ролик>.json $SP/captions/
cp -al public/local/head/<ролик>.mp4 $SP/local/head/   # + картинки и видео из пропсов
npx remotion bundle src/index.ts --out-dir /tmp/bundle --public-dir $SP
npx remotion render /tmp/bundle GTT-Head out/<ролик>.mp4 --props=<пропсы>.json
```
