# Aura Head — говорящая голова в стиле aura-robotics.ru

Формат для роликов Aura Robotics: Остап рассказывает про компании-производителей
роботов, поверх — фрейм в стилистике сайта. Композиция `Aura-Head`
(`src/aura-robotics/compositions/RobotTalk.tsx`), бренд — только `src/aura-robotics/theme.ts`.
Конвейер подготовки съёмки тот же, что у GTT Head (`npm run head -- --prepare`,
паузы, студийный звук, расшифровка, `--grade`), отличается только композиция и
набор элементов. Заведено 03.10.2026 по запросу владельца; статус — **проба**,
правила уточняются после первых реальных роликов.

## 1. Откуда стиль

Сайт: светлый фон (`#f8f6f3` / белый), чёрный Inter, кислотно-жёлтый `#fff65d`
только как маркер под ключевыми словами, тонкие серые рамки `#d9d7d5`,
чёрные пилюли-кнопки, карточки с радиусом 16, «листы в клетку» в первом
экране, тёмная полоса `#262626` с большими цифрами («Более 100
производителей · 17 городов»), бегущая строка заводов «AGIBOT — Шанхай ·
UBTECH — Шэньчжэнь», робот-маскот в правом нижнем углу, который машет,
кивает, прыгает между секциями и показывает на кнопку «Подобрать решение».

## 2. Набор элементов

| Элемент | Проп | Где в кадре | Для чего |
| --- | --- | --- | --- |
| Знак на круге | `logo` {`size`, `ring`, `ringSecondsPerTurn`, `reassembleEverySeconds`, `shineEverySeconds`} | верх, 0,09 высоты (Reels 0,10) | Всегда в кадре: монограмма AR на белом круге, кольцо «AURA ROBOTICS» крутится, знак пересобирается из элементов и бликует (раздел 3) |
| Робот-маскот | `bot` {`side`, `sizeFraction`, `look`, `gestures`, `auto`, `hidden`, `spots`} | у знака; ходит к карточкам с пунктами и по своим точкам | Объёмный, как на сайте. Дышит, моргает, смотрит на спикера; на события — жесты, на перечисления — подходит и показывает (раздел 4) |
| Крючок | `hookTop`, `hookBottom` | 0,245 высоты, первые 2,7 с | Верхняя строка на белой плашке, нижняя — на жёлтом маркере |
| Карточка факта | `cards` {`index`, `title`, `highlight`, `text`, `items`} | 0,245 высоты, вся ширина (с пунктами — 0,7) | Номер «01» мелким моно серым, заголовок чёрный с жёлтым маркером на ключевых словах, подпись серым. Как блок «Почему с нами дешевле» |
| Карточка завода | `factories` {`logo`, `name`, `city`, `note`} | там же | Логотип на белой плитке с рамкой, название, город. Логотипы — с сайта (`public/local/aura/logos/`) |
| Лист в клетку | `inserts` {`src`, `kind`, `label`, `cx`, `cy`, `widthFraction`, `aspect`, `tilt`} | правый верх, `cx 0,69 · cy 0,33 · ширина 0,5` | Фото или видео робота/цеха, карточка с сеткой и 3D-наклоном, подпись в углу («R&D-центр AgiBot») |
| Бегущая строка | `tickers` {`items` [{`name`, `city`}]} | 0,60 высоты, вся ширина | Перечисление заводов и городов, когда спикер их называет |
| Полоса с цифрой | `stats` {`prefix`, `value`, `suffix`, `label`} | 0,55–0,70 высоты | «Более 70 % гуманоидов мира собирают в Китае»: тёмная полоса, число растёт за 1,1 с, подпись серым с жёлтой чертой |
| Призыв | `cta` {`at`, `title`, `button`, `url`} | 0,52 высоты, до конца | Жёлтый блок с датами, чёрная пилюля «Оставить заявку», белая пилюля с адресом |
| Субтитры | `captionsSrc`, `captionsOffsetSeconds` | низ, 0,16 высоты (Reels 0,22) | Белая плашка, чёрный Inter 700, текущее слово под жёлтым маркером; страницы по 2–4 слова |
| Музыка | `music`, `musicVolume` | — | Тихо под голосом, вход 1,2 с, выход 2 с |

Все элементы кроме таблетки, робота и субтитров — события «на слово» с
`at`/`until` в секундах расшифровки. Ритм как в GTT Head: событие каждые
3–5 с, не два одного типа подряд, лицо (треть высоты и ниже) не перекрывать
дольше 4 с.

## 3. Знак: круг, кольцо, пересборка

Знак в видео — `AuraLogo` (`src/aura-robotics/components/AuraLogo.tsx`):
монограмма AR на белом круге с тонкой серой рамкой и жёлтой нитью, вокруг —
кольцо «AURA ROBOTICS · AURA ROBOTICS ·», которое медленно крутится
(`logo.ringSecondsPerTurn`, 16 с). Кегль кольца считается от радиуса так,
чтобы целое число повторов закрыло окружность без шва. При появлении пять
элементов монограммы (две ножки A, перекладина, дуга и ножка R) слетаются
с пружиной; раз в `logo.reassembleEverySeconds` (12 с) знак рассыпается и
собирается заново; раз в `logo.shineEverySeconds` (4 с) по буквам пробегает
блик. Диаметр — `logo.size` (0,24 ширины). Лаборатория — `Aura-LogoLab`
(белый, тёмный, поверх съёмки).

Вектор монограммы снят с оригинального `logo.png` по измерениям, формы не
менялись: `public/aura/mark.svg` (монограмма), `public/aura/logo.svg`
(с надписью, надпись — трассировка), `public/aura/wordmark.svg`.
Аватары для Instagram (1080×1080) — `out/deliver/aura-logo/`: монограмма на
белом, монограмма с кольцом, монограмма на тёмном; превью в круге рядом.

## 4. Робот: жесты, перемещения, правила

Робот — `AuraBot3D` (`src/shared/components/effects/AuraBot3D.tsx`):
перенос 3D-маскота сайта (`/js/aura-mascot.js`, three.js) в Remotion без
зависимостей — та же скелетная модель из боксов, цилиндров и сфер, та же
камера и свет, свой SVG-рендер с сортировкой граней по глубине. Палитра
сайта: светлый `#f8f6f3`, тёмный `#262626`, жёлтый `#fff65d`, глаз и
индикаторы светятся жёлтым. Лаборатория поз — `Aura-BotLab`.

| Жест | Длина | Когда (`bot.auto: true`) |
| --- | --- | --- |
| `wave` | 2,8 с | на крючке, 0,5 с |
| `nod` | 1,4 с | на карточке факта без пунктов |
| `point` | 2,2 с | на каждом пункте перечисления, на вставке, на призыве |
| `scan` | 3,0 с | на карточке завода |
| `jump` | 1,75 с | на цифре (укорочен, `jumpHeight 0.5`) |
| `shrug` | 1,8 с | только вручную: «а кого обходить стороной» |

**Перемещения.** Робот живёт у знака (`homeSpot`: справа от круга, ноги на
его нижней кромке). Карточка с `items` зовёт его к себе: карточка сужается до
0,7 ширины, робот за 0,9 с идёт к её правому краю (шагает ногами, корпус
повёрнут по ходу), встаёт лицом к пунктам (`facing −55°`) и показывает рукой
на каждый пункт по мере появления (пункты — через 0,9 с), затем возвращается
к знаку. Свои точки — `bot.spots: [{ at, x, y, facing }]` (ноги в долях
кадра); переход между точками всегда 0,9 с с шагом. Рост — `bot.sizeFraction`
(0,15 высоты кадра); взгляд в покое — на спикера (`bot.look −0,6`), на время
вставки — в её сторону.

Чего не делать: не ставить два жеста ближе 2 с, не отправлять робота на лицо
спикера (точки — верхняя треть и края), не менять палитру.

## 5. Конвейер

1. Съёмка → `npm run head -- --prepare <ролик> --grade clean` (пресет
   `clean`: без оттенка, чтобы белые плашки и жёлтый маркер не спорили с
   картинкой).
2. Расшифровка вычитывается; имена заводов проверяются по каталогу сайта
   (`aura-robotics.ru/catalog`), логотипы складываются в `public/local/aura/logos/`.
3. Монтажный стол: таблица событий по секундам → `<Composition id="Aura-Head-<ролик>">`
   в `Root.tsx` (регистрация руками, как `Aura-Head`).
4. Стоп-кадры: `npx remotion still <bundle> Aura-Head-<ролик> out/aura/<кадр>.png --frame=N`
   — крючок, каждая карточка, вставка, цифра, призыв. Судья по
   `docs/head-style.md`, раздел 6.
5. Рендер сторис и Reels (`safeZone: "reels"`), сжатие, `out/deliver/`.

Пример и дефолтные пропсы — `Aura-Head` в `Root.tsx` (съёмка
`local/head/s28-third.mp4`, ролик про Robotics Expedition).
