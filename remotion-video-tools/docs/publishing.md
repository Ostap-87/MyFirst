# Публикация в Instagram

Автоматическая публикация возможна **только через официальный Instagram Graph
API** от Meta. Готового коннектора в этой среде нет, сторонние сервисы-посредники
требуют доступа к аккаунту и нарушают правила площадки.

## Что нужно получить один раз

1. **Instagram Business или Creator аккаунт.** Личный аккаунт API не публикует.
   Переключается в настройках приложения: Настройки → Тип аккаунта.
2. **Страница Facebook, связанная с этим аккаунтом.** Требование Meta: API
   работает через страницу, даже если вы ей не пользуетесь.
3. **Приложение в [Meta for Developers](https://developers.facebook.com/)**
   с продуктом Instagram Graph API и разрешениями:
   - `instagram_basic`
   - `instagram_content_publish`
   - `pages_show_list`, `pages_read_engagement`
4. **Долгоживущий токен доступа** (60 дней, продлевается без переавторизации).
5. **ID вашего Instagram-аккаунта** (`IG_USER_ID`) — получается запросом
   `GET /me/accounts?fields=instagram_business_account`.

Токен и ID передаются скрипту переменными окружения — в репозиторий они не
коммитятся:

```bash
export IG_ACCESS_TOKEN="EAAG..."
export IG_USER_ID="17841400000000000"
```

## Как устроена публикация

Instagram **не принимает файлы напрямую** — он забирает медиа сам по публичной
HTTPS-ссылке. Поэтому порядок такой:

1. Карусель рендерится локально (`npm run carousel`).
2. Слайды уезжают в публичную папку репозитория `instagram/<имя>/`.
3. Instagram забирает их по ссылкам `raw.githubusercontent.com`.
4. API создаёт контейнер на каждый слайд, затем контейнер карусели, затем
   публикует.

Этот же механизм уже работает для картинок Telegram-постов в `tg-images`.

## Ограничения площадки

| Что | Предел |
| --- | --- |
| Публикаций в сутки | 25 (лимит Meta на аккаунт) |
| Слайдов в карусели | от 2 до 10 |
| Формат картинок | JPEG, публичная HTTPS-ссылка |
| Reels | до 90 секунд, MP4/MOV, H.264 |
| Срок жизни токена | 60 дней, продлевается |

Чего API **не умеет**: публиковать в Stories (только Business-аккаунтам через
отдельное разрешение), ставить теги товаров, публиковать от личного аккаунта.

## Проверка перед первой публикацией

Прогон без отправки показывает, какие ссылки уйдут в Instagram и что с
подписью, но ничего не публикует и не пушит:

```bash
npm run publish -- --carousel robotics-expedition --dry-run
```

## Схема запросов

```
POST /{ig-user-id}/media            image_url=<raw-ссылка>&is_carousel_item=true
   -> creation_id на каждый слайд, ждём status_code=FINISHED

POST /{ig-user-id}/media            media_type=CAROUSEL&children=<id,id,...>&caption=<текст>
   -> creation_id карусели

POST /{ig-user-id}/media_publish    creation_id=<id карусели>
   -> id опубликованного поста
```

Для Reels вместо первого шага — `media_type=REELS&video_url=<ссылка>`;
обработка видео на стороне Instagram занимает до минуты, поэтому статус
контейнера опрашивается дольше.
