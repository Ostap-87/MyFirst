# Правила проекта

Remotion-проект (React + TypeScript) для трёх независимых брендов:
**GlobalTechTour (GTT)**, **Aura Robotics**, **ostapdotcenko** (личный бренд).

## Выбор бренда

1. Если в задаче упомянут бренд — используй **только** `theme.ts`, шрифты и
   ассеты его папки. Не смешивай стили разных брендов в одной композиции.

   | Слова в задаче                              | Папка                 | Префикс композиций |
   | ------------------------------------------- | --------------------- | ------------------ |
   | «GTT», «тур», «делегация», «globaltechtour» | `src/globaltechtour/` | `GTT-*`            |
   | «Aura», «робот», «robotics»                 | `src/aura-robotics/`  | `Aura-*`           |
   | «личный бренд», «ostapdotcenko», «блог»     | `src/ostapdotcenko/`  | `Personal-*`       |

2. Если бренд не назван явно, но идёт правка уже открытой или последней
   обсуждаемой композиции — продолжай в её контексте, сам не переключайся.
3. Если контекст не ясен вообще — спроси, для какого из трёх брендов задача,
   прежде чем писать код.

## Эффекты

4. Новый визуальный эффект (переход, анимация появления, моушн-приём) всегда
   создавай в `src/shared/components/effects/` как отдельный переиспользуемый
   компонент с Zod-схемой параметров — **никогда** не пиши анимацию inline
   внутри композиции конкретного бренда.
   Создавать через `npm run new-effect -- --name MyEffect --what "что делает"`,
   соглашения — в `src/shared/components/effects/README.md`.

## Что спрашивать, а что делать сразу

5. Перед структурными изменениями — новая папка верхнего уровня, смена стека,
   смена версии Remotion, новая зависимость — спрашивай подтверждение.
   Точечные правки (текст, цвет, тайминг, параметр существующего компонента) —
   делай сразу.

## Разбор моушн-дизайна из референсных видео

Когда прислали ссылку или файл чужого видео с эффектом, который нужно повторить:

1. **Кадры.** Если это файл — разбей нужный фрагмент через ffmpeg:
   `ffmpeg -i ref.mp4 -ss <старт> -t <длительность> -vf fps=30 frames/frame_%03d.png`.
   Если это ссылка — скачай фрагмент или попроси файл.
2. **Опиши движение словами по кадрам:** что движется, откуда куда
   (позиция / масштаб / прозрачность / поворот), с какой кривой
   (плавно / пружина / резко), сколько это длится в секундах **и кадрах**.
3. **Напиши компонент-эффект** в `src/shared/components/effects/` через
   `npm run new-effect`, используя `interpolate` и `spring` под замеренные тайминги.
4. **Отрендери тестовый кадр или фрагмент** на нейтральных данных:
   `npx remotion still Shared-EffectsLab out/test.png --frame=<кадр>`.
5. **Сравни свой рендер с кадрами референса** — позиция, скорость, тайминг.
   Заметно расходится — поправь параметры кривой и повтори рендер.
6. **Авторские права.** Если референс — узнаваемый фирменный приём конкретной
   студии или бренда (не общий тип эффекта, а уникальная реализация) — спроси,
   делать точную копию или «в похожем духе», прежде чем продолжать.

Результат сохраняй как обычный эффект — со временем из этого и складывается
библиотека.

## Команды

| Команда                                                                  | Что делает                                                                     |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------------------ |
| `npm run dev`                                                            | Remotion Studio: превью всех композиций                                        |
| `npm run new-effect -- --name X --what "…"`                              | Новый эффект + экспорт + строка в README                                       |
| `npm run new-composition -- --brand aura --name Y [--format vertical]`   | Новая композиция бренда + регистрация в `Root.tsx`                             |
| `npm run set-theme -- --brand gtt --key colors.accent --value "#2563eb"` | Точечно меняет одно значение в `theme.ts` (без `--value` — показывает текущее) |
| `npm run parse-plan`                                                     | Разбирает контент-план Telegram-постов в `data/posts.json`                     |
| `npm run render-batch -- --brand gtt --limit 3`                          | Пакетный рендер вертикальных роликов по постам (`--dry-run` — только план)     |
| `npm run transcribe -- --audio <файл>`                                   | Пословные субтитры из аудио локальным whisper.cpp                              |
| `npm run lint`                                                           | ESLint + `tsc --noEmit`                                                        |
| `npx remotion render <id> out/<id>.mp4`                                  | Рендер видео                                                                   |
| `npx remotion still <id> out/<id>.png --frame=N`                         | Рендер одного кадра                                                            |

Форматы `--format`: `landscape` (1920×1080), `vertical` (1080×1920), `square` (1080×1080).
Бренды в `--brand`: `gtt`, `aura`, `personal` (принимаются и полные имена папок).

## Форматы кадра и безопасные зоны

Ролики делаются под три формата: 16:9, 9:16 и 1:1 / 4:5.

- **Размеры задавай долей кадра**, а не пикселями: `const { fs, sp } = useFormat()`,
  дальше `fontSize: fs(0.08)` — 8% ширины. Кегль в пикселях, подобранный на
  кадре 1920, в кадре 1080 выглядит вдвое крупнее положенного.
- **Текст оборачивай в `<SafeArea platform="telegram" />`** (`telegram`, `reels`,
  `shorts`, `landscape`, `feed`). В вертикали низ кадра перекрыт подписью и
  кнопками — заголовок «по центру» на телефоне уезжает под интерфейс.
  Проп `guides` рисует границы зоны прямо в Studio.

## Данные: ролики из контент-плана

`npm run parse-plan` разбирает `../tg-images/20-day-batch.md` в `data/posts.json`
(дата, бренд, компания, slug, заголовок, лид, CTA, путь к картинке с учётом
версий `-v2`, кандидаты-числа для счётчика). `npm run render-batch` рендерит по
этим данным вертикальные ролики, собирая бандл один раз на весь пакет.

Картинки берутся из `tg-images` через симлинк `public/tg-images`: `staticFile`
видит только содержимое `public`, поэтому новые источники ассетов подключай
так же, а не абсолютным путём.

## Технические соглашения

- **Шрифты — только локальные** из `public/fonts` через `src/shared/fonts`.
  Noto Sans SC подставляется фоллбэком автоматически — в текстах есть китайские
  названия, которых нет в Inter, Unbounded и Golos Text.
  Не подключай Google Fonts по сети: рендер не должен зависеть от сети,
  а `@font-face` через CSS `@import` Remotion не дожидается — кадр уедет
  системным шрифтом.
- **Время считаем в кадрах**, не в секундах: при смене fps композиции
  анимация не должна разъезжаться.
- **Случайность — только `random(seed)`** из Remotion, иначе рендер
  невоспроизводим.
- **Никаких `background-image`** — Remotion не ждёт загрузки картинки из CSS,
  и кадр может уйти без неё (правило `@remotion/no-background-image`).
  Картинка — `<Img>`, генеративная текстура — inline SVG-фильтр.
- **Цифры в кадре — через `CountUp`**, а не простым текстом: контент держится
  на статистике, а отсчёт удерживает зрителя до конца сцены.
- **`Root.tsx` не правим руками в блоках с маркерами** `new-composition:*` —
  туда пишет скрипт. Всё остальное в файле править можно.
- После изменений прогоняй `npm run lint` — `tsc` ловит несоответствие пропсов
  схемам до рендера.
