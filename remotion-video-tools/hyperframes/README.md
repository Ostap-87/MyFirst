# Head-Recut: плашки поверх говорящей головы

Второй конвейер формата **Head**. Съёмка идёт нетронутой, поверх ложатся
графические плашки, нарезанные по расшифровке. Собирается не в Remotion, а в
HyperFrames — HTML вместо React.

    npm run recut                         собрать все ролики из clips.json
    npm run recut -- --only st15-campus   один или несколько через запятую

Дальше в папке ролика:

    cd hyperframes/batch/st15-campus
    npx hyperframes check     линт, разметка, вёрстка, контраст
    npx hyperframes render --sdr    рендер в MP4

## Когда брать этот конвейер, а когда Remotion

**`GTT-ChinaStories` (Remotion)** — основной. Субтитры по словам, крючок,
перебивки со скриншотами сайта, концевая карточка. Всё, где нужен полный
монтаж, а не только надписи поверх.

**Head-Recut (здесь)** — когда нужны только плашки на готовой съёмке.
Быстрее в сборке и даёт две вещи, которых в Remotion нет:

- **аудит контраста.** `check` меряет каждый текст против того, что под ним,
  и не пропускает ниже 3:1. Так нашлась ошибка в нашем же шаблоне: белый знак
  по светлому небу давал 1,57:1 — во всех девятнадцати уже собранных роликах;
- **настоящий WebGL.** Тетраэдр знака здесь на three.js, как на сайте. В
  Remotion аппаратного ускорения при рендере нет, и ту же фигуру пришлось
  считать вручную и рисовать в SVG.

Плата за это — скорость: примерно **20 секунд машинного времени на секунду
видео** при программной отрисовке. Ролик на 20 секунд считается 6–7 минут.

## Геометрия

Взята из `ChinaStories`, а не подобрана заново, — ролики стоят в одной ленте
и должны выглядеть одинаково.

| Что               | Доля кадра | Пиксели при 1080×1920 |
| ----------------- | ---------- | --------------------- |
| Знак сверху       | 0,135      | 259                   |
| Стопка плашек     | ~0,203     | 390                   |
| Нижняя плашка     | —          | нижний край на 1660   |

**Почему нижняя плашка однострочная.** Замер по всем шестнадцати исходникам:
подбородок стоит между 1440 и 1540, а строка ответа сторис начинается на 1670.
В худшем ролике остаётся около 130 пикселей. Двухстрочная плашка или крупное
число в столбик где-нибудь обязательно наедут на лицо.

**Почему в стопке не больше трёх.** Четвёртая достаёт до линии волос.
Перечисление длиннее расходится группами — см. `st15-campus`, там шесть
кампусов идут двумя тройками.

## clips.json

```jsonc
{
  "name": "st15-campus",      // имя папки в batch/
  "src": "src15-tight",       // файл из public/local, без .mp4
  "seconds": 32.2,            // длительность ролика
  "cards": [                  // нижние однострочные плашки
    { "at": 5.0, "out": 9.9, "text": "Обучение", "second": "в кампусах" },
    { "at": 16.68, "out": 30.3, "num": "3", "text": "дня", "second": "внутри компании" }
  ],
  "plates": [                 // накопительный список сверху
    { "at": 10.24, "until": 12.5, "text": "Alibaba", "kind": "term" },
    { "at": 14.64, "until": 16.4, "text": "ByteDance", "kind": "accent" }
  ]
}
```

- `at` — когда появляется, `out` — когда начинает гаснуть, `until` — когда
  стопка расходится. Без `until` плашка стоит до конца ролика: так оформляется
  последняя в перечислении, она остаётся выводом.
- `second` — вторая часть строки голубым, `num` — число слева.
- `kind`: `term` белая, `accent` белая с синей полосой слева, `struck` тёмная
  с красной чертой поверх текста.

**Тайминги берутся из расшифровки, а не расставляются равномерно.** Опорные
секунды ищутся по первому слову фразы:

```bash
npm run transcribe -- --audio public/local/src15-tight.mp4 --out data/captions-st15.json
```

Плашка, поставленная «на глаз», расходится с речью на полсекунды, и это
заметно сразу.

## Что ломается молча

- **Элементы без `data-start` в рендер не попадают.** В предпросмотре они
  видны, в готовом файле их нет. Так пропал фирменный блок, и поймалось это
  только сравнением кадра из MP4 с кадром из снапшота. **Проверять готовый
  файл, а не предпросмотр.** Быстрая проверка — временно поставить
  `data-duration="1.4"` и отрендерить: тридцать секунд вместо восьми минут.
- **Время ставится на `<video>`, а не на обёртке.** Если разметить обоих,
  линтер ругается на вложенный тайминг.
- **`<video>` обязан иметь `id`,** иначе в рендере он замирает на первом кадре.
- **Шрифты из навыка только латинские.** `Inter-400-latin.woff2` на русском
  даёт квадраты. Берём `public/fonts/Inter.ttf`.
- **`data-no-timeline`** нужен композиции без GSAP, иначе продюсер ждёт
  регистрации таймлайна 45 секунд на каждом рендере.

- **Рендер только с `--sdr`.** Айфон снимает в HLG, и без флага HyperFrames
  сам переключается на HDR: HEVC 10 бит и около 12 ГБ промежуточных кадров
  на полминуты видео. При нехватке диска рендер падает на старте — так
  упали два самых длинных ролика пакета. Для сторис HDR не нужен, цвет в
  SDR тот же.

## Установка навыков

Навыки HyperFrames в репозитории не лежат — это 19 МБ стороннего кода,
исполняемого с полными правами агента. Ставятся в начале сессии:

    npx skills add heygen-com/hyperframes

Состав и версии зафиксированы хешами в `skills-lock.json` в корне.
Подробнее — [docs/hyperframes.md](../docs/hyperframes.md).

## Что лежит в .gitignore

`batch/` — в каждом собранном ролике копия исходной съёмки на десятки
мегабайт; пересобирается из `clips.json` одной командой. `vendor/` — three
качается по версии из `build.mjs`, gsap берётся из навыка.
