# Библиотека эффектов

Переиспользуемые моушн-приёмы проекта. Любая новая анимация живёт здесь,
а не inline внутри композиции бренда (CLAUDE.md, правило 4).

Эффекты нейтральны к брендам: они не знают о цветах и шрифтах и работают
с любым содержимым, которое им передали в `children`.

Создать новый: `npm run new-effect -- --name MyEffect --what "что делает"`
Посмотреть на нейтральных данных: `npx remotion studio` → композиция `Shared-EffectsLab`.

| Эффект             | Что делает                                                                                                                                                       | Параметры (значение по умолчанию)                                                                                                                                  |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `FadeIn`           | Плавное появление: прозрачность 0→1 плюс небольшой подъём снизу. Кривая `Easing.out(cubic)` — быстрый старт, мягкая остановка, без перелёта                      | `delayInFrames` (0), `durationInFrames` (18), `translateY` (24)                                                                                                    |
| `SlideInSpring`    | Выезд текста или объекта с пружиной: у движения есть инерция и лёгкий перелёт за конечную точку                                                                  | `direction` (`"up"`), `distance` (80), `delayInFrames` (0), `damping` (14), `mass` (1), `stiffness` (100), `fade` (true)                                           |
| `ZoomParallax`     | Плавный наезд на фото с параллаксом текста поверх: фото увеличивается и едет по Y, текст — в противоположную сторону с меньшей амплитудой                        | `src` (`""` — заглушка), `zoomFrom` (1), `zoomTo` (1.18), `driftY` (−40), `parallaxStrength` (60), `durationInFrames` (150), `overlayOpacity` (0.35)               |
| `GlitchTransition` | Глитч-переход между двумя сценами: кадр режется на горизонтальные полосы со случайными сдвигами, поверх — RGB-расщепление (красный и голубой каналы расходятся)  | `transitionAtFrame` (60), `durationInFrames` (10), `sliceCount` (12), `intensity` (90), `rgbSplit` (14), `seed` (`"glitch"`); плюс обязательные `before` и `after` |
| `CountUp`          | Отсчёт числа с торможением к финалу: 0 → 3 790. Русское форматирование (неразрывный пробел в разрядах, запятая в дробной части, «млн» и «млрд»), табличные цифры | `from` (0), `to` (100), `delayInFrames` (0), `durationInFrames` (45), `decimals` (0), `compact` (false), `prefix` (`""`), `suffix` (`""`)                          |
| `FilmGrain`        | Плёночное зерно и виньетка поверх кадра: возвращает текстуру плоским заливкам и маскирует бандинг на градиентах. Кладётся последним слоем                        | `opacity` (0.07), `grainSize` (2), `vignette` (0.35), `animate` (true), `blendMode` (`"overlay"`)                                                                  |
| `MotionTrail`      | Шлейф за быстро движущимся объектом — имитация смаза затвора. Обёртка над `<Trail>` из @remotion/motion-blur, внутрь кладётся уже анимированный блок             | `layers` (8), `lagInFrames` (1), `trailOpacity` (0.5)                                                                                                              |

### Готовые переходы

Рутинные стыки сцен закрывает `@remotion/transitions` — `TransitionSeries`
с `slide`, `wipe`, `fade`, `clockWipe`. Свой `GlitchTransition` остаётся
фирменным акцентом, а не единственным способом склейки. Пример —
в `src/shared/MotionLab.tsx`.

### Выбор blendMode у зерна

`overlay` рассчитан на светлые кадры: на тёмном фоне он почти не виден
(разброс яркости фона 1.2 против 3.4 у `screen` — замерено на кадре
Shared-MotionLab). Для тёмных сцен берите `screen` или `soft-light`.

## Соглашения

- **Параметры необязательны.** Каждый эффект принимает `Partial` своих
  параметров и подставляет значения из `<имя>Defaults`, так что
  `<FadeIn delayInFrames={12}>` — валидный вызов.
- **Zod-схема на каждый эффект.** Экспортируется как `<имя>Schema` и годится
  для `<Composition schema={...} />`: параметры можно крутить прямо в правой
  панели Remotion Studio, не трогая код.
- **Детерминированность.** Случайность берём только из `random(seed)` Remotion —
  иначе кадры «кипят» между прогонами и рендер невоспроизводим.
- **Время в кадрах, не в секундах.** Так эффект не разъезжается при смене fps
  композиции.

## Как добавить эффект из референса

Порядок разбора чужого видео (ffmpeg → описание движения → компонент → сверка
рендера с кадрами оригинала) описан в `CLAUDE.md`, раздел «Разбор моушн-дизайна
из референсных видео».
| `SpinningTetra` | вращающийся тетраэдр логотипа: 3D-проекция без WebGL | `delayInFrames`, `durationInFrames` |
| `SiteCutaway` | перебивка со скриншотом сайта: плавная прокрутка длинной страницы в кадре | `delayInFrames`, `durationInFrames` |
| `CameraMoves` | Движения камеры по готовой съёмке: `punch` — быстрый зум (наезд за 4 кадра, резкий возврат), `push` — лёгкий наезд через весь отрезок, `cut` — мгновенная смена крупности, как склейка со второй камерой. Центр — на глазах | `moves` ([]), `originX` (0.5), `originY` (0.4), `punchFrames` (4) |
| `PhotoCards` | Фотокарточки внахлёст: въезжают сбоку по одной (пружина без перелёта, 12 кадров) с поворотом −4°/0°/+4°, следующая ложится поверх; уходят всей стопкой. В вертикали — на грудь, в горизонтали — сбоку от спикера | `items` ([]), `stepFrames` (10), `side` (`"right"`), `widthFraction` (0.34), `topFraction` (по формату), `tilt` (4), `exitFrames` (8) |
| `PopWindows` | Всплывающие окна вокруг спикера: выскакивают по очереди с перелётом и поворотом ±3°, схлопываются разом. Гнёзда заданы, а не случайны: в вертикали — углы над головой и на плечах | `items` ([]), `stepFrames` (6), `sizeFraction` (0.3), `exitFrames` (8) |
| `FramedInsert` | Видео или фото в рамке со скруглением, белой обводкой и подписью: появление с масштаба 0,92 и прозрачности, уход прозрачностью. В вертикали — правый нижний угол, на плече | `src`, `caption`, `side` (`"right"`), `widthFraction` (0.5 / 0.44), `topFraction` (0.55 / 0.18), `fadeFrames` (8) |
| `WipeBroll` | B-roll на весь кадр: каждый кадр въезжает шторкой справа со светлой кромкой, внутри медленный наезд, геометка Cormorant Garamond внизу слева; блок уходит той же шторкой, открывая спикера | `items` ([], `caption` — геометка), `wipeFrames` (10), `zoom` (1.08), `labelBottomFraction` (0.27) |
| `SplitScreen` | Плавное деление экрана: шов едет снизу до середины (14 кадров, `inOut(cubic)`), спикер кадрируется в верхнюю часть — глаза встают на 0,31 под логотип, масштаб не меняется; снизу фото или видео с наплывом и медленным наездом, шов мягкий (растушёвка 110 px), низ показа затемнён под субтитры. Оборачивает слой спикера | `splits` ([]), `seam` (0.52), `focusY` (0.42), `eyesAt` (0.31), `transitionFrames` (14), `featherPx` (110), `line` (false) |
