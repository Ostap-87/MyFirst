# tg-images — общее хранилище картинок для Telegram-постов

Отдельное от сайтов место (репозиторий `Ostap-87/MyFirst`, публичный, ветка `master`) — сюда агент с доступом к Higgsfield кладёт сгенерированные картинки для Telegram-постов ГлобалТехТур и Aura Robotics, а другая сессия (публикующий ассистент) забирает их отсюда и собирает финальные посты.

## Структура

```
tg-images/
  globaltechtour/
    2026-08-16-nio-battery-swap.png
    2026-08-17-dji-drones.png
    ...
  aura/
    2026-08-16-evst-welding.png
    2026-08-17-borunte-industrial.png
    ...
```

## Правила именования

- Имя файла: `<YYYY-MM-DD>-<slug>.png`, где `<slug>` — короткий английский идентификатор темы (совпадает со slug'ом в документе с постами).
- Дата в имени — дата, на которую запланирован пост (не дата генерации).
- **Никогда не переиспользовать имя файла** — если генерируете новую версию той же картинки, добавляйте суффикс `-v2`, `-v3` и т.д. Telegram кэширует фото по URL, и переиспользование имени может привести к тому, что в канал уйдёт старая версия картинки, даже если файл на GitHub уже обновлён.

## Формат картинки

- Соотношение сторон: **4:5** (портретное, как у уже готовых примеров — DJI и EVST).
- **Без текста, без логотипов, без водяных знаков** в самой генерации — реальный логотип компании накладывается уже на стороне публикующей сессии отдельным шагом (компоновка через `brand_overlay.py`), не нужно пытаться вставить его в промпт.
- Промпты для каждой картинки — в документе с постами (см. `/workspace/claude-control/data/content-plan/20-day-batch.md` в репозитории `claude-control`).

## Доступ

Ссылка на готовый файл: `https://raw.githubusercontent.com/Ostap-87/MyFirst/master/tg-images/<project>/<filename>.png` — работает сразу после пуша в `master`, без какой-либо сборки/деплоя (репозиторий публичный).
