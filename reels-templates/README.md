# Шаблоны рилсов в стиле @andreykchina — разбор приёмов и сборка

В комплекте: T0 «Виртуальная студия» (свой кабинет OSTAP DOTCENKO - GTT, ночь/утро) + T1–T4 по разбору референса.

Разбор сделан по 4 стоп-кадрам. Движение (скорость смены кадров, анимации) по статике видно не полностью — там, где приём выведен из жанра, а не виден на кадре, это помечено как «вероятно».

---

## 0. Общая ДНК стиля (повторяется во всех роликах)

**Одна «студия» на всю серию.** Лаундж премиального отеля: тёплые торшеры, тёмные панорамные окна, логотип на стене в расфокусе. Зритель узнаёт автора по кадру раньше, чем по лицу. Для себя: выбери 1–2 постоянные локации и снимай в них пачками по 5–10 роликов.

**Образ-контраст.** Тёмный пиджак + белая рубашка без галстука + очки. Лицо и рубашка — самые светлые объекты в кадре, взгляд сразу идёт туда. «Эксперт/аналитик», а не «блогер».

**Свет.** Мягкий тёплый ключ спереди-сбоку, фон на 1,5–2 ступени темнее, малая ГРИП (фон размыт). Лампы в кадре работают как «практики» — дают глубину.

**Звук.** Петличка на лацкане (видна на фото 3) — чистая речь без эха.

**Субтитры — главный визуальный маркер.** Всегда в одной точке (~52–54 % высоты кадра), белый жирный округлый шрифт, тёмная обводка + мягкая тень, 2–5 слов на экран, 1–2 строки, без знаков препинания, регистр как в речи. Похоже на дефолтные субтитры CapCut; в шаблонах — Nunito Black (бесплатный, с кириллицей).

**Цвет.** Тёплые средние тона, слегка приглушённые тени — лёгкий «teal & orange».

**Подпись = заголовок-хук.** «Блогеры в Китае похоронили продажи селлеров», «Увлечение hyrox в 🇨🇳 даже сильнее…». Конфликт или удивление + Китай.

**Что говорит статистика на скринах.** Ролик про hyrox: 5 019 лайков / 4 133 репоста. Ролик про селлеров: 537 / 229. Разница ≈ ×10. Трендовая тема + яркий «живой» B-roll с людьми вирусится сильнее, чем аналитика у стола. Рабочая формула: аналитика подаётся через визуально яркий тренд.

## T0 — Виртуальная студия (фон кабинета OSTAP DOTCENKO - GTT)

**Идея.** Один раз сгенерированный кабинет с видом на Шанхай (ночь и утро) + ты, снятый у любой ровной стены. Меняешь только одежду — студия всегда одна и та же.

**Ассеты и промпты** — в `studio/PROMPTS.md`: ссылки на скачивание, все промпты генерации и шаблон промпта для новых вариантов (закат, дождь, сезонные).

**Как устроен реализм (слои снизу вверх):**
1. Статичный PNG кабинета — мебель, лампы и надпись гарантированно не «дышат» (главный недостаток AI-видео).
2. Видео-луп только в зоне окна, через маску. Маску строит `scripts/window-mask-from-loop.py`: находит в лупе пиксели, которые двигаются (город), и делает из них PNG с мягким краем.
3. Бесшовность: `SeamlessLoop` запускает повторы внахлёст с кроссфейдом 0,6 с — стык не виден.
4. Ты — видео с прозрачным фоном. Цвет подгоняется под фон (`speakerGrade` для ночи теплее и темнее, для утра светлее), тёплое свечение по краю силуэта (`rimLight`) имитирует свет ламп.
5. Край стола из того же PNG кладётся ПОВЕРХ тебя (`deskTopPct`) — ты сидишь «за» столом, а не висишь в воздухе.
6. Лёгкий расфокус фона 1,5 px (малая ГРИП), виньетка и общее зерно — склеивают всё в одну «плёнку».

**Съёмка без оборудования.**
- Свет: окно спереди или под 45°, днём. Для ночной студии — окно с той же стороны, где на картинке торшеры (слева), и в монтаже теплее.
- Фон: ровная однотонная стена, отличная по цвету от одежды, ты в метре от неё.
- Камера: телефон на уровне глаз, 1080×1920, место штатива отметь скотчем — кадр всегда одинаковый.
- Звук: петличка или беспроводные наушники.
- Одежда: любая, кроме зелёной и блестящей.

**Вырезка себя:**
- стена → `bash scripts/cutout.sh take.mp4 public/speaker-keyed.webm` (AI, без хромакея), либо CapCut «Удалить фон», либо Higgsfield remove background;
- зелёный фон (если появится) → `bash scripts/key-green.sh take.mp4 public/speaker-keyed.webm`.

**Сборка:**
```bash
# 1. положи ассеты
public/studio/night.png  night.mp4  morning.png  morning.mp4
public/speaker-keyed.webm  (+ speaker-keyed-audio.m4a, если звук отдельно)

# 2. маски окна (один раз на каждый луп)
python scripts/window-mask-from-loop.py public/studio/night.mp4   public/studio/night-mask.png
python scripts/window-mask-from-loop.py public/studio/morning.mp4 public/studio/morning-mask.png

# 3. проверка в Studio: debug = "mask" (маска зелёным) и "diff" (если окно «съехало» — будет видно контуры)
npx remotion studio

# 4. рендер студийного ролика
npx remotion render T0-Studio-Night out/studio-night.mp4

# 5. этот файл — speakerSrc для T1 / T3 / T4 (сплиты, панч-ины, скрины):
npx remotion render T1-SplitGradient out/final.mp4 --props='{"speakerSrc":"../out/studio-night.mp4", ...}'
```
Проще: скопируй `out/studio-night.mp4` в `public/` и укажи `"speakerSrc":"studio-night.mp4"`. Для T2 (стикер) используй сам `speaker-keyed.webm` — он уже с прозрачным фоном.

**Подгонка (props в Studio справа):** `speakerScale` / `speakerOffsetY` — размер и посадка в кадре (голова на ~30–35 % высоты); `deskTopPct` — чтобы край стола совпал с картинкой; `windowRect` — если маску не строил, прямоугольник окна в долях кадра; `grain` 0.05–0.09.

**Проверка реализма перед публикацией:** ролик в полноэкранном режиме на телефоне → смотри край волос и плеч, совпадает ли тёплый свет на лице с лампами, не дрожит ли интерьер, нет ли рывка на стыке лупа.

HyperFrames-версия: `hyperframes/t0-virtual-studio.html` (прямоугольник стола и маска окна те же, луп из двух клипов внахлёст).

## 1. Фото 1 → шаблон T1 «Сплит-скрин с градиентной склейкой»

**Что в кадре.** Верх ~56 % — спикер крупным планом (голова + плечи, камера на уровне глаз, взгляд чуть мимо объектива). Низ — фото/видео по теме (атлеты hyrox). Между половинами **нет линии**: нижний слой растворяется в верхний градиентом ~150–200 px. Субтитры стоят ровно на шве.

**Зачем это работает.**
- Лицо держит доверие, B-roll даёт «доказательство» — оба в кадре одновременно.
- Субтитр на шве прикрывает склейку и находится в центре взгляда.
- Градиент вместо линии выглядит «дорого», а не как шаблон из приложения.

**Параметры.** Шов 56 % высоты (1075 px из 1920). Склейка 160 px. Спикер в режиме сплита приближается на ~12 %, чтобы лицо оставалось крупным. B-roll — медленный наезд 1.00 → 1.08 (Ken Burns). Переход «весь кадр ↔ сплит» — вероятно, жёсткий (на склейке фраз).

**Файлы.** `remotion/src/templates/SplitGradient.tsx` (композиция `T1-SplitGradient`), `hyperframes/t1-split-gradient.html`.

**Что заполнить.** `speakerSrc`, список `brolls` с `fromMs/toMs`, `captionsFile`.

## 2. Фото 2 → шаблон T2 «Спикер-стикер поверх B-roll»

**Что в кадре.** B-roll на весь экран (забег hyrox в выставочном зале). Спикер **вырезан из фона** и наложен в правый нижний угол, обрезан краями кадра. Вокруг силуэта — толстая белая обводка, как у наклейки (die-cut sticker), плюс тень. Жест руками («домик») — живая эмоция. Субтитры на той же высоте, что и везде.

**Зачем это работает.**
- Зритель видит само событие почти на весь экран, но автор остаётся «в кадре» как проводник — эффект «я тут, смотри».
- Белая обводка отделяет спикера от пёстрого фона и даёт фирменную «коллажную» эстетику.
- Смена раскладки (T1 → T2) каждые 2–4 секунды удерживает внимание без смены локации.

**Параметры.** Ширина вырезки ~90 % кадра, уходит за правый край на ~17 % и за нижний на ~29 % (голова на ~57 % высоты). Обводка 12 px. Вход — выезд снизу с поворотом 6° → 0° (вероятно; популярная анимация стикера).

**Технически важное.** Нужен видеоролик спикера с альфа-каналом:
- `remotion/scripts/cutout.sh` — AI-вырезка через `backgroundremover` → `cutout.webm` + отдельный звук;
- альтернативы с лучшим качеством волос/краёв: Robust Video Matting, CapCut «Удалить фон», или подключённый у тебя Higgsfield (remove_background);
- лайфхак съёмки: снимай такие фразы на однотонном фоне, отличном по цвету от одежды, — вырезка станет чище.

**Файлы.** `CutoutOverBroll.tsx` (`T2-CutoutOverBroll`), `hyperframes/t2-cutout-sticker.html`. Обводку делает SVG-фильтр `StickerFilter` (альфа → жёсткий край → расширение на N px → белая заливка).

## 3. Фото 3 → шаблон T3 «Говорящая голова + реквизит»

**Что в кадре.** Спикер за столом, полный кадр. На столе распечатанная инфографика на планшете-клипборде, в руке маркер-указка, сбоку ноутбук. Взгляд в лист, а не в камеру: «разбираю документ при тебе». Субтитр одной строкой на той же высоте.

**Зачем это работает.**
- Физический реквизит = ощущение экспертизы и «реальных цифр». Это не «мнение», а «разбор».
- Маркер даёт руке действие — кадр не статичен даже без монтажа.
- Лист с цифрами можно показать крупно отдельной врезкой.

**Параметры (вероятно, стандарт жанра).** Медленный дрейф-наезд +5 % за ролик. «Панч-ины» — резкий зум 1.15–1.25 на ключевой фразе; со смещением точки масштабирования вниз (originY 0.75) это «наезд на лист». Лёгкая виньетка, тёплый грейд.

**Файлы.** `TalkingHeadPunchIn.tsx` (`T3-TalkingHead`), `hyperframes/t3-talking-head.html`. Заполнить `punchIns` (моменты ключевых фраз) и `inserts` (крупняк листа, снятый отдельно на телефон).

## 4. Фото 4 → шаблон T4 «Сплит со скрин-доказательством»

**Что в кадре.** Та же раскладка, что в T1, но внизу — **скриншот/запись экрана китайского приложения** (Taobao: поиск, цены ¥3, ¥2.01, ¥5.9, баннер 88VIP). Сверху спикер держит маркер (связь с предыдущей сценой). Субтитры на шве.

**Зачем это работает.**
- Скрин с ценами — неопровержимое доказательство, «это реально так».
- Китайский интерфейс сам по себе экзотика для русскоязычной аудитории — останавливает скролл.
- Одна раскладка (T1 = T4) делает монтаж единым: меняется только содержимое низа.

**Параметры.** Скрин масштабирован до ширины 1080 и плавно скроллится (ease in-out). Красные рамки «выскакивают» на цены (scale 1.3 → 1 с отскоком). Рамки — моё дополнение для усиления: на кадре автора их не видно, отключаются пустым `highlights`.

**Файлы.** Тот же `SplitGradient.tsx` с `type: "screen"` (`T4-ScreenProof`), `hyperframes/t4-screen-proof.html`.

## 6. Пайплайн

**1. Съёмка.** Одна локация, 1080×1920 или 4K по вертикали, петличка. Фразы для T2 — на однотонном фоне. Отдельно: крупняки реквизита, скрины/записи экрана приложений, B-roll с места.

**2. Remotion (основной путь).**
```bash
npx create-video@latest my-reels --blank
cd my-reels
# скопируй сюда src/ и scripts/ из папки remotion/
npx remotion add @remotion/captions @remotion/google-fonts @remotion/install-whisper-cpp
# положи медиа в public/: speaker.mp4, broll/..., screens/...
node scripts/transcribe.mjs public/speaker.mp4 public/captions.json   # субтитры (нужен ffmpeg)
bash scripts/cutout.sh public/speaker.mp4 public/cutout.webm          # только для T2
npx remotion studio                                                    # превью, правка props справа
npx remotion render T1-SplitGradient out/t1.mp4 --props='{"speakerSrc":"speaker.mp4","captionsFile":"captions.json","brolls":[{"src":"broll/01.jpg","fromMs":1500,"toMs":4500}]}'
```
В `Root.tsx` поменяй `DURATION` под длину ролика. После транскрипции открой `captions.json` и поправь опечатки (особенно названия брендов и китайские слова).

**3. HyperFrames (альтернатива: HTML + GSAP).**
```bash
npx hyperframes init my-reel        # создаст проект
# замени index.html на нужный t*-*.html, медиа и шрифт Nunito-Black.ttf — в assets/
node captions-to-words.mjs ../remotion/public/captions.json   # вставь WORDS в шаблон
npx hyperframes preview
npx hyperframes render
```
Контракт шаблонов: корень с `data-composition-id / data-width / data-height / data-duration`, медиа с `class="clip"` и `data-start / data-duration / data-track-index`, видео `muted` + звук отдельным `<audio>`, GSAP-таймлайн `paused` и зарегистрирован в `window.__timelines`. Сверь с актуальной документацией HyperFrames — формат ещё развивается, названия CLI-команд могут отличаться.

## 7. Готовые промпты для Claude Code

Открой папку проекта в Claude Code и используй:

> Собери рилс по шаблону T1-SplitGradient. Исходник: public/speaker.mp4. Сделай транскрипцию scripts/transcribe.mjs, исправь опечатки в captions.json. По смыслу текста расставь B-roll из public/broll/ (каждый 2–4 секунды, смена на границе фраз, не чаще раза в 2 с). Длительность композиции — по длине speaker.mp4. Отрендери в out/.

> Смонтируй ролик, чередуя шаблоны: хук первые 3 с — T3 с панч-ином; дальше T1 и T2 по очереди каждые 3–4 с; все цифры и цены — через T4 со скрином public/screens/*.png и рамками на ценах. Вынеси общий таймлайн в один JSON и собери мастер-композицию из Sequence.

> Подстрой THEME в styles.ts под мой бренд: шрифт [название], акцентный цвет [HEX], субтитры на 55 % высоты. Проверь рендер одного кадра на 5-й секунде через `npx remotion still`.

> Возьми шаблон hyperframes/t4-screen-proof.html, подставь assets/taobao.png, найди на скрине блоки с ценами и выставь координаты рамок, синхронизируй их появление со словами из WORDS, где упоминаются цены.

> Собери ролик в виртуальной студии. Мой дубль: public/take.mp4 (снят у стены). Вырежи фон через scripts/cutout.sh, построй маску окна для public/studio/night.mp4 скриптом window-mask-from-loop.py, открой T0-Studio-Night и подгони speakerScale, speakerOffsetY и deskTopPct так, чтобы голова была на ~33 % высоты, а край стола перекрывал меня по пояс. Проверь режимом debug "mask", потом отрендери out/studio-night.mp4 с субтитрами из captions.json.

> Сделай ту же студию утренней: T0-Studio-Morning, маска для morning.mp4, грейд спикера светлее и холоднее, чтобы свет на лице совпадал с дневным окном. Сравни кадр 5-й секунды ночной и утренней версии через `npx remotion still` и покажи оба.

> Возьми out/studio-night.mp4 как speakerSrc и смонтируй финальный рилс: хук 3 с — T3 с панч-ином, дальше T1 с B-roll из public/broll/, цены — T4 со скрином. Субтитры единые на весь ролик.

> Сгенерируй новый вариант студии по шаблону из studio/PROMPTS.md (раздел 5): [закат / дождь на стекле / Китайский Новый год], затем луп по промпту из раздела 4 и маску окна. Надпись OSTAP DOTCENKO - GTT и ракурс не менять.
