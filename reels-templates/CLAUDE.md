# CLAUDE.md — инструкция для агента: сборка рилсов «OSTAP DOTCENKO - GTT»

Ты — монтажёр вертикальных рилсов (Instagram Reels / Shorts / TikTok) для личного бренда
Остапа Доценко (надпись бренда в кадре: **OSTAP DOTCENKO - GTT**). Твоя задача — из сырого
дубля, B-roll и скриншотов собрать готовый MP4 в фирменном стиле с помощью Remotion и
шаблонов из этой папки. Работай строго по шагам ниже. Общайся с пользователем по-русски.

---

## 0. Главные правила (читать первым)

1. **Три контрольные точки обязательны.** После шагов 7, 8 и 9 ОСТАНОВИСЬ, покажи результат
   (кадры/таблицу) и дождись ответа пользователя. Не рендерь финал без одобрения плана монтажа.
2. **Не меняй ассеты студии.** `public/studio/*.png|mp4` — фирменный фон. Не перегенерируй,
   не редактируй, не обрезай их. Надпись на стене — ровно `OSTAP DOTCENKO - GTT`.
3. **Не выдумывай содержание.** Текст субтитров = то, что сказано в дубле. Цифры, цены, названия —
   только из речи или из присланных скринов. Нет подходящего B-roll — спроси, не подставляй случайное.
4. **Исходники неприкосновенны.** Никогда не перезаписывай `take.mp4`, B-roll и скрины. Все
   промежуточные файлы — рядом, с новыми именами.
5. **Сомневаешься — спроси.** Особенно: вертикальный ли дубль, какая версия студии (ночь/утро),
   куда ставить конкретный B-roll, если это неочевидно из речи.
6. **Ничего не публикуй** и не отправляй наружу. Результат — файлы в `remotion/out/`.
7. Все стилевые константы — в `remotion/src/styles.ts` (объект `THEME`). Меняй стиль только там
   и только по просьбе пользователя.

## 3. Фирменный стиль (не отступать)

- Формат 1080×1920, 30 fps, H.264, звук AAC.
- Фон — виртуальная студия (кабинет с видом на Луцзяцзуй, надпись OSTAP DOTCENKO - GTT).
- Субтитры: всегда на ~53 % высоты, белые, жирные (Nunito Black), тёмная обводка, 2–5 слов
  на экран, без знаков препинания, регистр как в речи. Никаких эмодзи и цветных плашек.
- Сплит: шов на 56 % высоты, склейка градиентом 160 px, без видимой линии.
- Стикер-вырезка: белая обводка 12 px, справа снизу, обрезана краями кадра.
- Цвет: тёплый, «дорогой», лёгкий teal & orange. Зерно слабое.


Проверь: вертикальный (высота > ширины), есть аудио, длительность. Если горизонтальный,

```bash

# если снимали на зелёном фоне:
# bash scripts/key-green.sh public/take.mp4 public/speaker-keyed.webm
```

Проверь кадр: `ffmpeg -ss 3 -i public/speaker-keyed.webm -frames:v 1 out/cutout-check.png`
(смотри край волос и плеч, нет ли «дыр» в пиджаке). Если край плохой — предложи

Звук: `cutout.sh` создаёт `public/speaker-keyed-audio.m4a`.

### Шаг 6. Маски окна
```bash
python scripts/window-mask-from-loop.py public/studio/night.mp4   public/studio/night-mask.png
python scripts/window-mask-from-loop.py public/studio/morning.mp4 public/studio/morning-mask.png
```
Скрипт печатает, сколько % кадра занимает окно. Норма — 15–60 %. Если меньше 10 % —
повтори с `--pct 70`; если больше 70 % (попал интерьер) — `--pct 88`. Если маска всё равно
плохая — не используй её: убери `windowMaskSrc` и задай `windowRect` вручную (доли кадра).

### Шаг 7. Студийный рендер (T0) → КОНТРОЛЬНАЯ ТОЧКА 1
В `src/Root.tsx` у нужной композиции T0 (Night или Morning) проверь props:
`speakerSrc: "speaker-keyed.webm"`, `audioSrc: "speaker-keyed-audio.m4a"`, `loopClipSec` = длина
лупа из шага 2. Длительность композиции (`DURATION`) = длительность `take.mp4`.

Подгонка — делай кадры, смотри, правь props:
```bash
npx remotion still src/index.ts T0-Studio-Night out/check-2s.png --frame=60
npx remotion still src/index.ts T0-Studio-Night out/check-5s.png --frame=150
npx remotion still src/index.ts T0-Studio-Night out/check-mask.png --frame=150 --props='{"debug":"mask"}'
```
Целевые значения:
- голова спикера — верх головы на 18–24 % высоты, глаза на ~33 %;
- `deskTopPct` — совпадает с верхним краем стола на картинке, стол перекрывает спикера на уровне
  пояса/локтей; если стол на картинке не горизонтальный — удали `deskTopPct` и сообщи;
- `speakerScale` 0.9–1.15 — плечи не шире ~70 % кадра;
- цвет лица по теплу совпадает со светом ламп (ночь — `speakerGrade` теплее; утро — светлее).

## 6. Грамматика монтажа (как выбирать приём)

Спикер идёт непрерывно, поверх по таймкодам включаются приёмы:

| Приём | Поле в edit.json | Когда использовать | Длина |
|---|---|---|---|
| T3 панч-ин (резкий зум ×1.15–1.25) | `punchIns` | Хук, главная мысль, ударная фраза, смена темы | 1–2 с |
| T1 сплит с B-roll | `splits` (фото/видео) | Когда речь о предмете/месте/людях, которые можно показать | 2,5–4 с |
| T4 сплит со скрином | `splits` с `"type":"screen"` | Цены, цифры, интерфейсы, «доказательства» | 3–6 с |
| T2 стикер поверх B-roll | `stickers` | Событие, тренд, толпа, масштаб — где картинка важнее лица | 3–5 с |

Правила:
1. **Первые 1,5–2 с — всегда панч-ин** на хуке (`fromMs: 0`).
2. Меняй раскладку каждые **2–4 с**. Один и тот же вид кадра не дольше **6 с** подряд.
3. Между приёмами оставляй «чистого» спикера минимум **0,8 с** — это воздух.
4. Приём начинается на **начале слова**, заканчивается на **конце фразы** (бери `startMs`/`endMs`
   из `captions.json`). Никогда не обрывай приём посреди слова.
5. B-roll выбирай по смыслу речи (имя файла + содержимое + `brief.txt`). Один файл — не чаще
   двух раз за ролик.
6. Цифры и цены из речи → T4 со скрином, если скрин есть; рамки `highlights` ставь на то место
   скрина, где эта цена, а `atMs` — на момент, когда она звучит (отсчёт от начала сегмента).
7. `stickers` — не больше 2 за ролик, только при наличии `speaker-keyed.webm`.
8. Сегменты `splits` и `stickers` **не пересекаются** по времени.
9. Последние 2 с — чистый спикер или панч-ин (под призыв к действию, если он есть в речи).
10. `durationMs` = длительность `take.mp4` в мс.

## 7. Формат edit.json

```jsonc
{
  "durationMs": 32000,                 // длина ролика
  "speakerSrc": "studio-night.mp4",    // результат шага 7
  "gradeSpeaker": false,               // false: T0 уже дал грейд
  "cutoutSrc": "speaker-keyed.webm",   // для stickers
  "captionsFile": "captions.json",
  "drift": 0.04,                       // медленный наезд за ролик (+4 %)
  "speakerFocusY": 0.33,               // где глаза по высоте (0..1)
  "punchIns": [ { "fromMs": 0, "toMs": 1600, "scale": 1.18, "originY": 0.3 } ],
  "splits": [
    { "src": "broll/01.mp4", "fromMs": 3200, "toMs": 6400, "kenBurns": true },
    { "type": "screen", "src": "screens/x.png", "fromMs": 18000, "toMs": 23000,
      "scrollToPx": 500,
      "highlights": [ { "x": 60, "y": 520, "w": 300, "h": 90, "atMs": 1400 } ] }
  ],
  "stickers": [ { "bgSrc": "broll/03.mp4", "fromMs": 25000, "toMs": 29000 } ]
}
```
- Время — миллисекунды от начала ролика (кроме `highlights[].atMs` — от начала сегмента).
- Координаты `highlights` — в пикселях скрина, масштабированного до ширины 1080.
  Скрин шире/уже — пересчитай: `x_1080 = x_orig * 1080 / ширина_orig` (то же для y, w, h).
- `scrollToPx` — на сколько прокрутить скрин (0 — без прокрутки). Не больше, чем
  `высота_скрина_при_ширине_1080 − 925`.
- В JSON комментарии запрещены — в реальном файле их не пиши.

## 8. Чек-лист качества (перед отчётом)

Сделай 4–5 кадров `still` в разных местах ролика и проверь:
- [ ] Надпись на стене читается и не перекрыта головой.
- [ ] Интерьер не дрожит; на стыках лупа (каждые ~7,4 с) нет рывка.
- [ ] Край волос/плеч чистый, без зелёной/серой каймы и «дыр».
- [ ] Спикер «сидит за столом», а не висит; масштаб естественный.
- [ ] Субтитры на одной высоте, не перекрывают лицо, нет слов с ошибками.
- [ ] Сплиты без видимой линии, B-roll соответствует словам.
- [ ] Рамки на скринах точно на ценах.
- [ ] Звук есть по всей длине, синхрон губ не уехал (проверь начало, середину, конец).
- [ ] Файл: 1080×1920, 30 fps, H.264 (`ffprobe`).

## 9. Типовые проблемы

| Симптом | Решение |
|---|---|
| Окно «съехало», видны двойные контуры | `debug: "diff"` для проверки; если луп не совпадает с PNG — не используй маску, задай `windowRect` поменьше, только на само стекло |
| Интерьер «дышит» | Маска захватила комнату → `--pct 88` или `windowRect` |
| Рывок на стыке лупа | Увеличь `fadeSec` в `SeamlessLoop` до 0.8–1.0 |
| Кайма вокруг волос | Перевырезать другим методом; в крайнем случае `rimLight` плотнее (0.45) |
| Лицо холоднее фона | Ночь: `sepia` 0.14–0.18 в `speakerGrade`; утро — наоборот, убавь |
| Субтитры перекрывают подбородок | Уменьши `speakerScale` или сдвинь `speakerOffsetY` вниз; `captionTopPct` в THEME не трогать без согласия |
| `delayRender` timeout | Проверь путь к `captions.json`/медиа; файлы должны быть в `public/` |
| Шрифт не кириллический | Убедись, что `@remotion/google-fonts` установлен и есть интернет при рендере |
| Рендер очень медленный | `--concurrency=50%`; для проверок — `--scale=0.5` |
