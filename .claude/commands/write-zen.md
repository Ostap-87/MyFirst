Аргументы команды (в этом порядке): $ARGUMENTS
1. сайт-источник: `aura-robotics`, `globaltechtour` или `ostapdotcenko`
2. тема поста
3. seed-ключевые слова (через запятую) — использовать для формулировок и
   подзаголовков, не пихать искусственно, если это портит текст

Шаги:

1. Открой `CLAUDE.md` в корне проекта и найди раздел, соответствующий
   указанному сайту (aura-robotics.ru / globaltechtour.ru / ostapdotcenko.ru).
   Голос, структура и запреты этого раздела обязательны для всего текста.
   Если тема касается фактов/цифр про роботов и рынок робототехники —
   обязательно соблюди правило "Актуальность: факты про роботов" из того же
   файла (только конец 2025 и весь 2026 год; если свежих данных нет — прямо
   скажи об этом, не бери более старые цифры).
2. Открой `publishing-rules.md`, раздел **"Яндекс Дзен"**.
3. Напиши ПОЛНОСТЬЮ ОРИГИНАЛЬНУЮ статью под формат Дзена — не сокращай и не
   адаптируй текст, написанный для другой площадки. Структура: заголовок,
   вступление (первые 2-3 предложения самодостаточны — по ним формируется
   анонс-карточка), подзаголовки, 800-1500 слов, вывод. Отметь текстом
   `[МЕСТО ДЛЯ КАРТИНКИ: <короткое описание, что изобразить>]` минимум один
   раз — реальную картинку сюда не вставляешь, только маркер места.
4. Прогони готовый текст по чек-листу из `publishing-rules.md` → "Яндекс
   Дзен" и укажи результат явно (заголовок ≤140/оптимум 15-25 — факт; длина
   в словах — факт; есть ли ссылки в теле — факт; самодостаточность
   вступления — факт).
5. Выведи: заголовок, сам текст, затем блок "Проверка по чек-листу" с
   результатом по каждому пункту. Если что-то не укладывается — явно
   напиши, что именно и почему, не подгоняй цифры.
