Аргументы команды (в этом порядке): $ARGUMENTS
1. сайт-источник: `aura-robotics`, `globaltechtour` или `ostapdotcenko`
2. тема поста
3. seed-ключевые слова (через запятую)

Шаги:

1. Открой `CLAUDE.md`, раздел нужного сайта — голос и запреты обязательны,
   но сожми под формат короткого поста (без потери голоса).
2. Открой `publishing-rules.md`, раздел **"Facebook"**.
3. Напиши ПОЛНОСТЬЮ ОРИГИНАЛЬНЫЙ пост под Facebook — короткий, разговорный,
   первая строка = хук (отдельного поля заголовка нет). Дай ДВА варианта:
   (а) короткий пост 40-80 символов для максимального охвата, (б) вариант
   "история" до 250 слов, если тема это оправдывает.
4. Прогони оба варианта по чек-листу из `publishing-rules.md` → "Facebook":
   есть короткий вариант 40-80 символов — факт; "история" ≤250 слов —
   факт; первая строка работает как самостоятельный хук — факт.
5. Выведи оба варианта и блок "Проверка по чек-листу" по каждому. Если
   что-то не укладывается — явно скажи, что и почему.
