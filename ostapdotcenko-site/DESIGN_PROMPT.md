> Как использовать: вставьте документ целиком в AI-инструмент (ChatGPT, Claude, v0, Lovable, Cursor) и попросите собрать сайт по нему.
> Правило для агента: данные из части D — реальные данные владельца; не выдумывать и не «улучшать» имена, цифры и ссылки без явного указания.

# ЧАСТЬ A. ЗАДАЧА И ОБЩИЕ ПРИНЦИПЫ

Собери **одностраничный персональный сайт-портфолио** специалиста по B2B-маркетингу и международному бизнесу (Россия ↔ Китай ↔ ЮВА) **на трёх языках: русский (основной), английский, китайский**, с переключателем в шапке.

Эстетика — **«швейцарский плакат, найденный в архиве»**: светлая «костяная» бумага, чернильная типографика, маркерно-жёлтые акценты, синие и красные служебные цвета, жёсткие офсетные тени, квадратные углы, технические моноширинные подписи и «паспортные» печати. Ощущение ручной печати, бумаги и штампов. Никакого глянца.

Стек (рекомендуемый): React + Vite + Tailwind CSS; шрифты Google Fonts; вся анимация с фолбэком `prefers-reduced-motion`.

Структура страницы сверху вниз:
1. Шапка (фиксированная) + прогресс-бар чтения + переключатель языков
2. Открытие: гигантское имя, бейдж, живые часы, статистика, двойная бегущая строка
3. Обо мне (sticky-портрет, тезисы, экспертиза, языки)
4. Карьера (тёмный таймлайн; первая строка «2025 — н. в.» — намеренно пустая)
5. Результаты (асимметричная сетка реальных цифр)
6. Проекты (аккордеон из 6 реальных кейсов)
7. Консультации (продажа услуг, 3 тарифа с ценами)
8. Блог (статьи + видео)
9. Рекомендации (открытки со скотчем и марками)
10. Упоминания в СМИ (реальные кликабельные ссылки)
11. Вне работы (хобби + фотогалерея)
12. Контакты (форма с валидацией, часы городов, соцсети) + футер

## B5. ФИРМЕННЫЕ ПРИЁМЫ (обязательные)

1. Жёсткие офсетные тени: `box-shadow 8px 8px 0 rgba(25,25,34,0.12)`; hover → `12px 12px 0 #FFD92E`.
2. Границы `2px solid ink`; тонкие — `1px rgba(25,25,34,0.25)`.
3. **Скруглений нет** (исключение — точки и круглые печати).
4. Точечная сетка: `radial-gradient(rgba(25,25,34,0.13) 1px, transparent 1px) / 26px 26px`.
5. Миллиметровка на тёмном: `rgba(255,255,255,0.045) 1px / 52px` в две оси.
6. Зерно поверх всего: фиксированный слой, SVG feTurbulence `baseFrequency 0.9`, `opacity 0.055`, pointer-events none.
7. Печать-штамп: круг ~110px, `border 3px dashed #FF4A1F`, поворот −12°, mono-текст.
8. Открытки-отзывы: поворот −2.5…1.5°, «скотч» 96×24px `yellow/80`, «марка» 36×44px с пунктирной красной рамкой; hover: rotate(0) + подъём + жёлтая тень.
9. Полароиды: белая рамка `10px 10px 40px`, mono-подпись, Ken Burns на фото.
10. Двойная бегущая строка под открытием: поворот −1°, верхняя `ink/bone`, нижняя `yellow/ink`, направления встречные.

## B6. АНИМАЦИИ (все — с фолбэком prefers-reduced-motion)

- **Scramble-расшифровка имени:** глифы `▓▒░#/\<>+=*%&@$ΞΔЖ`, 34 мс/кадр, фиксация слева направо; вторая строка — задержка 550 мс.
- **Line-mask reveal:** `translateY(118%) → 0`, `cubic-bezier(0.19,1,0.22,1)`, 1s, каскад +110 мс.
- **Маркерное выделение:** жёлтая полоса `background-size 0% → 100%` (0.72em, позиция 0 78%), при появлении во вьюпорте.
- **Scroll-reveal:** `translateY(26px) + opacity 0 → 1`, 0.85s, IntersectionObserver однократно.
- **Count-up метрик:** 1300 мс, ease-out `1-(1-p)^3`.
- **Бегущая строка:** `translateX(0 → -50%)`, 30–40s linear infinite, контент ×2, пауза при hover.
- **Круговой бейдж:** 22s linear infinite, текст по окружности, в центре красная ↗.
- **Ken Burns:** `scale(1) → scale(1.16) translate(-2.5%, 2%)`, 16s alternate infinite.
- **Живые часы:** 1 раз/сек (Intl timeZone).
- **Прогресс чтения:** полоса 3px `#FFD92E` вверху шапки.
- **Аккордеон:** `grid-template-rows 0fr → 1fr`, 500 мс.
- **Hover-правила:** ↗ сдвигается по диагонали на 2px; карточки поднимаются с растущей жёсткой тенью.
- **Форма:** ошибки — красная рамка + «▲ текст» mono 10.5px; успех — зелёная галочка + номер обращения в рамке.

## B7. РЕЦЕПТЫ КОМПОНЕНТОВ

# ЧАСТЬ C. ТЕХНИЧЕСКАЯ АРХИТЕКТУРА (для агента-разработчика)

## C1. ТРИ ЯЗЫКА (RU / EN / 中文)

- Весь контент — в трёх словарях `src/i18n/ru.ts`, `en.ts`, `zh.ts` одинаковой структуры (тип задаётся русским: `type Content = typeof ru`).
- Переключатель `RU | EN | 中文` в шапке: активный = инверсия `bg-ink text-yellow`; дублируется в мобильном меню. Выбор в `localStorage("lang")`; при смене — `document.documentElement.lang` (`ru` / `en` / `zh-CN`) и полный перевод всего контента без сброса структуры/скролла.
- **Не переводятся:** e-mail, телефон, ссылки соцсетей, цифры метрик, названия компаний в бегущей строке (Мегамаркет / Сбер, Alibaba Group, AliExpress…).

## C2. ФОТО ЧЕРЕЗ GITHUB

- Все изображения — в `public/img/` репозитория; имя файла прописывается в словарях (поля `img`), путь строится функцией `photo(name)`.
- Поток: 1) загрузить файл в `public/img/` (commit) → 2) вписать имя файла в `src/i18n/ru.ts|en.ts|zh.ts` → 3) при деплое (GitHub Pages) фото подхватывается по `/img/<имя>`.
- Альтернатива: `GITHUB_RAW_BASE` в `src/i18n/index.tsx` = `https://raw.githubusercontent.com/USER/REPO/main/public/img/` — загрузка напрямую из GitHub.
