# AGENT GUIDE — сайт-портфолио «Остап Доценко»

> Инструкция для AI-агента (Cursor, Claude Code, Copilot и др.), который будет **поддерживать и наполнять** готовый сайт.
> Дизайн-спецификация и весь реальный контент — в `DESIGN_PROMPT.md`. Этот файл — только про операции «как сделать».

---

## 0. ГЛАВНЫЕ ПРАВИЛА

1. **Единственный источник контента — словари** `src/i18n/ru.ts`, `src/i18n/en.ts`, `src/i18n/zh.ts`. Любой текст меняется **во всех трёх файлах синхронно** (структура задаётся `ru.ts`, тип `Content = typeof ru` — если поле добавлено в один файл, его обязаны получить все три, иначе упадёт сборка).
2. **Не трогать разметку** (`src/components/*.tsx`) и стили (`src/index.css`), если задача — правка контента. Разметка правится только при изменении дизайна (сверяться с `DESIGN_PROMPT.md`, части B).
3. **Не менять контакты** (`PERSON` в `src/i18n/index.tsx`: e-mail, телефон, соцсети) и **реальные ссылки СМИ** без явной команды владельца.
4. Цифры, имена компаний и метрики — **реальные**; не «округлять» и не украшать.
5. После любой правки — `npm run build`: сборка должна пройти без ошибок.

## 2. РЕЦЕПТЫ (пошагово)

### 2.1. Заполнить пустую строку карьеры «2025 — н. в.»
1. В `src/i18n/ru.ts` найти `career.entries[0]` (флаг `empty: true`).
2. Вписать реальные `role`, `company`, `chips[]`; **удалить** строку `empty: true`.
3. Продублировать перевод в `en.ts` и `zh.ts` (там тоже `entries[0]`).
4. `npm run build`.

### 2.2. Переписать «Обо мне»
Править только `about.*` в трёх словарях: `bio1`, `bio2`, `education`, `expertise[]`, `langs[]` (`name/level/pct` — pct задаёт длину шкалы). Заголовок — `about.lines[]`.

### 2.3. Сменить/уточнить имя и водяные знаки
`hero.firstName`, `hero.lastName`, `hero.watermark` в трёх словарях + подпись в шапке берётся автоматически. Титул вкладки — `index.html`.

### 2.4. Изменить цены и состав консультаций
`consulting.packages[]`: `name`, `price`, `desc`, `features[]`, `badge` (только у «популярного»). Цены — строки, можно «от ₽ …». CTA автоматически подставит название в тему письма.

### 2.5. Опубликовать статью в блоге
Добавить объект в `blog.articles[]` (все три словаря):
```ts
{ tag: "Тема", time: "8 мин", title: "Заголовок", excerpt: "Анонс 1–2 строки", full: "Тезисы 3–5 строк", link: "" }
```
`link` — внешняя публикация (необязательно; пустая = без ссылки).

### 2.5.1. Автопостинг новой статьи в Facebook + LinkedIn (обязательный шаг)
После публикации новой статьи (добавлена в `blog.articles[]` во всех трёх словарях — ru/en/zh, изменения задеплоены):
```
node scripts/post-to-facebook.mjs <slug>
```
Скрипт берёт `title` + `excerpt` из `src/i18n/ru.ts` И `src/i18n/en.ts` (нужны обе — статья должна быть переведена на английский к этому моменту) и постит через один общий Make.com сценарий (см. `claude-control/data/fb-config/webhooks.json` → `scenarios.ostapdotcenko`), который роутером разводит на две ветки: **Facebook** (текст+**галерея из всех инлайн-картинок статьи** на русском, свой Facebook-аккаунт, текст — заголовок + примерно половина статьи по словам, без ограничения по длине; поле Photos в модуле Make замаплено целиком на `images_ru` из вебхука) и **LinkedIn** (текст+**одна** картинка на английском, личный профиль, текст обрезается по границе параграфа так, чтобы уложиться в 2500 символов — LinkedIn криво отображает более длинные посты, см. `buildLimitedPost()` в скрипте; картинка — первая инлайн-картинка статьи, та же, что og:image, см. `generate-blog-html.mjs` `firstImage()`; LinkedIn-модуль "Create a User Image Post" не поддерживает несколько фото, поэтому там остаётся одна). Пересобрано с нуля 11.09.2026 — до этого был только Facebook; лимит длины для LinkedIn и галерея картинок для Facebook добавлены 14.09.2026.

### 2.6. Добавить видео
Объект в `blog.videos[]`: `{ title, platform: "YouTube" | "VK Video", duration: "12:07", url: "" }`.
Пока `url: ""` — карточка с тегом «скоро»; вписали ссылку — стала кликабельной.

### 2.7. Добавить упоминание в СМИ
Объект в `press.items[]`: `{ outlet: "ИЗДАНИЕ", tag: "интервью", title: "Заголовок", url: "https://…" }`. URL — реальный, проверять, что открывается.

### 2.8. Добавить фото в галерею «Путешествия»
1. Загрузить файл в `public/img/` (commit в GitHub), например `public/img/bangkok.jpg`.
2. Добавить в `life.shots[]` трёх словарей: `{ img: "bangkok.jpg", place: "Бангкок", caption: "Подпись" }`.
3. Полароид появится автоматически перед пунктирной карточкой «+ добавить кадр».
- Без деплоя: задать `GITHUB_RAW_BASE` в `src/i18n/index.tsx` = `https://raw.githubusercontent.com/USER/REPO/main/public/img/` — фото подтянутся напрямую из репозитория.

### 2.9. Заменить портрет на настоящее фото
Загрузить фото как **`public/img/portrait.jpg`** (commit). Он подхватится автоматически — менять код не нужно. Пока файла нет, работает сгенерированная заглушка.

### 2.10. Обновить контакты и соцсети
Только `PERSON` в `src/i18n/index.tsx` (едины для всех языков): `email`, `phone`, `phoneHref` (формат `+7985…`), `socials[]` `{ label, href }`.

### 2.11. Добавить/изменить хобби
Массив `life.hobbies[]` в трёх словарях — просто строки.

### 2.12. Поменять язык сайта по умолчанию
`src/i18n/index.tsx`: `useState<Lang>(() => … "ru")` — заменить `"ru"` на `"en"`/`"zh"`.
